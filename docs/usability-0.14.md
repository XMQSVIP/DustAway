# 0.14 人工试用方案

**人工可用性待验证：目前没有五名非开发者参与记录。** 自动化、截图检查和开发者操作不作为真实用户试用。

沿用 0.13 五人独立试用，不讲解界面。只读应用场景使用示例结果或专用夹具，避免在日常资料中进行删除实验。

| 任务 | 应观察的判断 |
| --- | --- |
| 微信正在运行，扫描出现日志和转储 | 能说出这版只能查看，关闭微信不会开放清理，无无效退出 |
| QQ 或 WPS 占用较大，但候选量很少/为零 | 能说出此次检查范围不等于整个应用占用，并找到对应管理指引 |
| 浏览器/临时文件可核对，应用规则只读 | 能仅核对可处理项目，不将只读大小计为预计释放空间 |
| 应用信息读取失败后重试 | 能区分能力未确认和扫描零候选，重试后原勾选保持 |
| 沿用正常保留与跨类别问题任务 | 能核对对应状态，并在无待处理问题时复核空间、回到原工作 |

记录参与者代号、时间、完成路径、求助次数、错误判断、无效退出/重扫次数及原话，不收集私人文件名或账号资料。

目标：至少四人无需提示找到有效下一步，五人均能区分只读结果与可删除候选。未满足时先修正文案和操作衔接，不据此开放规则权限。
