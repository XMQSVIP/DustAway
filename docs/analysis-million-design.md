# 百万级空间分析实现

参考 [tobi/disktree 的 Windows 批量枚举](https://github.com/tobi/disktree/blob/main/crates/disktree-core/src/windows.rs)、分配空间统计和协作取消，按 DustAway 的删除核验及资源要求实现有界处理，保留 Rust + Tauri + React。没有移植 GPUI、矩形树图、MFT 读取或提权扫描，没有复制其源代码。本轮使用独立测试包，版本号仍为 0.18.0。

## 读取与核验

Windows 使用 64 KiB 缓冲调用 `FileIdExtdDirectoryInfo`，普通文件不再逐个打开属性句柄。目录仍固定句柄并核对身份和父链；不支持该信息类时，在发布条目前回退到逐项读取。压缩和稀疏文件另外读取 `FileCompressionInfo`，失败记为未知。

普通文件用系统返回的分配大小。NTFS 驻留小文件可能返回很小的分配值，不能以“文件数 × 簇大小”估算。文件系统元数据、快照、卷保留空间不计入。逻辑长度和分配大小均以十进制字符串跨 IPC。

DA02 扫描证据保存完整卷身份、128 位文件 ID、大小、属性、创建/写入/变更时间和原始 UTF-16 名称。批量读取不提供范围外硬链接数，界面因此标为“清理前核验”。生成清单时重新打开文件、比较证据、检查硬链接数和保护条件；删除时继续执行原有冻结清单、身份及父链复核。

全局占用按卷和文件身份去重，各目录子树内分别去重；兄弟目录共享的占用不能相加。只有重复身份建立子树成员关系，避免普通文件的“身份 × 祖先”存储膨胀。重复身份的大小、已知分配量或修改时间冲突会回滚当前批次，保留已提交结果并标记不完整。

## 临时索引

生产分析使用独立会话的 SQLite WAL 数据库，包含名称、路径及元数据，不包含正文，不并入清理历史或诊断。默认位于程序数据目录，可通过设置中的系统选择器更换到本地固定 NTFS 位置。索引目录不进入分析。

每批最多 512 项、约 2 MiB 或 50 ms，前几个条目提前发布；通道最多 8 批。批次事务提交后发布快照。目录聚合缓存仅覆盖当前批次，长期状态在数据库。根目录优先列出子目录的队列最多 1,024 项或约 2 MiB；遍历深度最多 128 层。

数据库、WAL 和共享内存文件合计设 4 GiB 资源阈值，磁盘预留 2 GiB。写入和索引建立阶段检查，达到阈值保留可查询前缀并标记 `resource_limit`。5,000,000 条是防御上限，不保证任意目录形状都能达到。SQLite 页数限制不等于整个进程内存上限。

索引在异常退出后全部丢弃，使用 `synchronous=OFF` 避免可重建缓存的持久化屏障；清理日志的设置不变。正常退出、更换会话时关闭连接并清除已知索引文件；重启仅回收 UUID 标记匹配且锁未占用的本程序会话。不递归删除陌生内容，不恢复删除授权。

保留节点字符串 ID，与现有选择和清理接口兼容；真实文件身份压缩为 24 字节二进制键，普通文件路径由父目录与名称重建。本轮未同时改造清理标识协议来整数化所有字段，后续是否继续压缩由实测收益决定。

## 查询

列表、计数各有独立只读连接与取消标志，读取已提交快照。每页 200 项，游标绑定会话、筛选、排序及索引修订号，不做深页 OFFSET 扫描。扫描更新后的旧游标拒绝并返回第一页。总数异步计算，失败保留当前页并明确提示。

文件用途中的“已识别”和具体类别使用分类索引先筛选，再排序，避免空分类为了寻找 200 项而扫描整个大小排行；全体和未分类文件保留大小索引。目录用途统一使用目录专用覆盖索引，筛选、排序及异步计数不读取无关文件节点，最后只加载所选页的详情。没有再增加一次完整建索引过程，而是在已有目录索引中补齐筛选和排序字段。排行建立被取消时允许无索引回退，部分结果仍可读取。这不是对任意类别分布、深目录和实时磁盘负载的固定时延保证。

请求在 IPC 分派前注册；取消绑定 UUID，早到取消用有界队列记录，旧工作线程不能覆盖新请求。新会话和关闭索引先取消并等待旧读者。无法抢占正在阻塞的系统调用。

旧内存构造器和查询接口保留给既有库测试及兼容调用；生产 UI 根据 `query_api_version=2` 使用新接口。新接口包括 `read_analysis_page`、`cancel_analysis_query`、`get_analysis_count`、`get_analysis_storage` 和 `pick_analysis_storage`，均只授权本地主窗口。占用字段为 `allocated_bytes`、`allocation_unknown`，核验提示为 `verification_pending`。

## 验收方法

备份：`G:\my_ai\DustAway-backups\analysis-million-20261001-235701`，归档 SHA-256 为 `4b934bc2231068c8906e34c2d8dfef283fc13cc3eab524f48193c5b2bf251ef5`。旧基线从该副本独立构建，源代码未覆盖。

10 万、50 万夹具用旧、新 Release 各五轮交替测量，双方同为 50 万条限制；逐轮比较终态、条目数、文件数及逻辑/去重大小。百万和三百万夹具由新版本各完整运行三次。正式计时不与夹具生成、编译或原生界面测试并发。未清空系统文件缓存，不声称冷盘结果。

`scan_ms` 包含队列背压，`write_ms` 是消费者批次时间，两者重叠，不能相加；`index_ms` 单列排行索引阶段。私有内存用 Windows 进程计数器；索引峰值按 250 ms 采样加终值，可能漏掉瞬时峰值。查询时间只含后端返回，不含 WebView 绘制；新接口样本在旧接口查询后执行，已经预热保护检查和部分页面。其他项目活动按每轮记录，不声称主机完全空闲。最终结果见 [验收记录](verification-analysis-million.md)。
