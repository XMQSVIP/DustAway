## 实际缓存恢复实验

采用开发电脑现有 Edge 154.0.4258.37、独立配置及本地服务器，未使用用户浏览器配置。

1. 网页响应实验先确认 2 MiB 响应命中磁盘缓存，再只删除该专用响应文件。首次访问返回 `ERR_CACHE_READ_FAILURE`，下一次才重新下载。两个试验性 HTTP 规则因此撤回，未进入交付许可。原始结果：`edge-cache-recovery-v2/result.json`。
2. GPU 实验生成并使用图形缓存，关闭专用浏览器后只删除其 `GPUCache/data_1`，保留其他块文件及索引，再次启动。WebGL 着色器绘制的像素四轮一致 `[255,0,0,255]`、错误为 0；HTTP 缓存持续命中，没有网络请求或加载错误。原始结果：`edge-gpu-recovery-v1/result.json`。

这是缓存格式与恢复行为的独立检查，不是 Cherry/PyCharm 应用级真实验收。测试机没有这两款软件，应用级删除、再生成及正常使用仍为**未验证**。

- 普通下载首次超时；随后分段取得完整官方附件，并通过官方 SHA-256 校验后仅解包比对。
