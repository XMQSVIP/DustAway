# 0.12 普通用户试用

状态：**人工可用性待验证**。没有五人试用或访谈记录。由项目所有者安排五名非开发者，每人约 20 分钟；使用独立账号、标记合成夹具，经同意才录屏，不使用唯一个人资料验证删除。

主持人只说明任务，不提示按钮。需要帮助即记录为帮助后完成。

| 任务 | 核对点 |
| --- | --- |
| 电脑提示空间不足，检查能处理的内容 | 主动扫描，说明范围与关注磁盘不同 |
| 同时呈现可核对、运行中、只读、读取失败 | 正确说明各自下一步，不把关闭应用理解为解除只读限制 |
| 查看别的类别，取消一个文件 | 不误以为查看就是选择；已选总量与计划一致 |
| 浏览器暂时不能退出 | 可以先处理其他合格候选 |
| 部分成功：删除、跳过、失败、未处理 | 能打开对应报告和明细，知道不会自动重删 |
| 完成后空间仍没有明显增加 | 区分删除量和空间变化，回原保存/安装验证，再决定是否继续 |
| 零候选、未完整读取或全部取消选择 | 不混淆三种状态，不通过无效重扫恢复文件勾选 |

每人记录匿名编号、系统/缩放、经验、独立/帮助/未完成、耗时、原话、错误次数、求助与重扫次数。记录是否把只读或个人资料误认为可以删除。

验收目标：至少四人无提示完成扫描—判断—确认—复核；全部参与者能区分只读与可删除候选。出现删除范围误解先修正再复测。五人结果不外推为市场完成率，自动化测试不替代试用。
