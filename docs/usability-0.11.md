# 0.11 普通用户试用：范围、完整性与下一步

状态：**人工可用性待验证**。尚未开展真实用户访谈或五人试用，公开求助不代表需求比例。首轮安排五名非开发者，由项目所有者组织，每人约 20 分钟。目标为至少四人独立完成定位与合适操作；不是总体市场成功率。

## 准备与主持

使用独立测试账号与有标记的合成夹具。准备两个磁盘/目录、完整和部分统计、个人资料、系统资料、六条只读应用规则、可清理旧缓存、零候选与部分成功。不得使用唯一的个人资料测试删除，不填满日常磁盘。真实参与者主动同意后再记录屏幕，不收集无关路径。

主持人先读任务，不教按钮位置。参与者停顿时先询问其判断并记录，再给帮助；需要提示的任务不能算独立完成。

## 任务与观察

| 任务 | 成功理解与应记录的误解 |
| --- | --- |
| “电脑提示空间不足，请找主要占用。” | 能主动选择位置并启动，能说明结果属于哪一盘/目录。 |
| 完成 C 盘分析后改选 D 盘，暂时不启动；再查看上次结果。 | 不把上次 C 盘内容当 D 盘；能返回原结果，不丢失位置。 |
| 展示已识别为系统资料、但大小不完整的目录。 | 能分别说明用途与完整度；不把“待统计”理解成空目录或垃圾。 |
| 刷新失败、搜索未命中后继续查找。 | 能辨别旧读数时间和本次失败、已读范围未找到和完整未找到；能重试。 |
| 查看一个清理类别，但先不改变原来的范围；再明确加入下次扫描。 | 查看不误解为勾选；新增范围需要重新扫描，能回到原分析。 |
| 面对个人资料、运行中应用、验收未完成规则，选择合适操作。 | 不将大文件、个人资料或六条只读规则视为可以直接删除；退出应用不能解除验收限制。 |
| 使用夹具完成一次清理，或在应用内进行合适处理，再读结果。 | 分清实际删除、跳过/失败、同卷空间观察变化；能回到受阻的保存/安装核对，而非被诱导无限清理。 |

## 每人记录表

| 项目 | 记录 |
| --- | --- |
| 匿名编号、Windows、缩放、经验 | 待填写 |
| 定位与合适操作 | 独立完成 / 帮助后完成 / 未完成；耗时 |
| 范围判断 | 参与者原话；是否混淆待选与结果 |
| 完整性理解 | 原话；是否误读零、待统计、部分排名 |
| 下一步选择 | 操作与理由；是否出现直接删除误解 |
| 结果解读 | 实际删除与观察变化；是否核对原工作 |
| 中断、误点、帮助 | 发生位置、次数与原因 |

任何把个人资料或只读规则误认为可直接删除的观察，均须先修正界面与说明，再复测。保存原始记录和修正前后结果；没有参与者时继续保持待验证，自动化测试不能替代此项。
