## 匹配与说明边界

- 办公文稿和设计工程是用户内容。WPS 备份目录优先于 WPS 文件后缀，提醒核对恢复用途。
- 腾讯会议的 WEMTA/WEMTV 及配套 IDX 使用复合后缀识别，优先于默认录制目录；普通 MP4 只有位于已列出的目录时才推断为腾讯会议录制。
- uni_modules 可能含自行开发或修改的插件源码，不能与纯下载缓存混同；调试基座也可能需要配套原生插件与签名配置才能重建。
- Cocos 使用 `temp/asset-db/assets` 和 `temp/builder/log` 具体路径，不把任意 `library`、`temp`、`build` 目录认定为 Cocos。
- 鸿蒙只加入已确认的 oh_modules 与 HAP/HSP。HAR 与浏览器 HTTP Archive 同后缀，暂不单靠 `.har` 推断为鸿蒙包；`.app` 也不作通用鸿蒙判定。
- FIG、MG、WPS 等扩展名可能有其他用途，保留可能性措辞。只检查路径，不读取文档内容或确认实际所属软件。
- Foxmail 目前只覆盖来源明确列出的旧版路径，不宣称支持所有新版和自定义安装目录。
