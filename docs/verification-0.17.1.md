# 0.17.1：只展示与本次结果有关的应用

本轮修正清理总览将全部支持规则、零候选和实际文件混在一起的问题。默认结果行、状态数量及三个建议入口统一以 `foundFiles > 0` 为依据；单纯支持某应用、检测到后台进程或没有标准位置均不代表发现垃圾。

零候选但部分未读取、读取失败或中断时，另行提示未完成检查，支持展开查看类别与原因，不展示为“0 B 垃圾”。完整支持范围可主动展开，并明确不等于安装列表。新扫描重置展开状态。空间册仍承担查看规则范围的功能，增加对应说明。

扫描仍检查全部支持范围，因此卸载后遗留的缓存不会因安装状态被漏掉。选择状态、扫描接口、后端文件校验和删除权限均未改动。新增三条 Windows 与六条既有应用规则继续只读。
