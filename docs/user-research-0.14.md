# 0.14 双视角研究与取舍

核对日期：2026-09-27（资料）；实施记录采用 UTC。依据为源码、既有验收记录、公开求助和官方说明，**不是五名真实用户试用结果**。

## 用户视角

公开求助者已经知道 C 盘不足，仍不能判断 Local/Roaming 下哪些应用内容可以删除；常见目录名不足以解释影响。[用户原帖](https://www.reddit.com/r/WindowsHelp/comments/1omc7dj/which_folderssystem_folders_thats_safe_to_delete/)。只将其作为需求案例，不采用评论中的删除建议，也不推断需求比例。

当前代码有可复现的操作断点：后端在应用运行时先返回运行阻止原因，前端因此建议退出；但六条规则尚未通过真实应用验收，退出后仍不能清理。改进是把固定能力与临时条件分开，而不是要求用户反复重查。

微信/WPS 的过期诊断文件、经典 QQ 的三类网页缓存仅代表窄范围扫描。较小结果或零结果并不能说明聊天附件和文档备份没有占用。界面解释检查范围，并保留对应应用的处理指引。

## 产品经理视角

本轮衡量用户能否准确判断处理资格、是否发生无效退出或重扫、能否找到下一步。不以新增规则数和候选容量替代任务完成，也不把只读扫描工具称为删除验收工具。

优先交付：逐规则权威能力字段、共享决策和统计、只读范围说明、脱敏证据收集和完整性检查。固定六条只读，未加入 QQNT、聊天附件删除、升级安装、后台任务或遥测。现有用途识别改动保留并纳入完整回归。

## 官方指引依据

[WPS 官方 2026 年 7 月版本说明](https://bbs.wps.cn/topic/93227)将应用缓存、云文档缓存、文档备份和路径管理分别处理，提供首页“全局设置 → 存储管理”入口。由此更新离线指引中的分类说明；已固定支持的 12.8.2.18205 不因此获得新版菜单或清理兼容性认定，旧版本没有入口时使用应用内帮助。

其他七份应用指引沿用 [0.13 来源与限制](user-research-0.13.md)，没有冒充逐版本重新实测。应用内处理完成后回到拂尘刷新空间，不计入拂尘报告的删除量。
