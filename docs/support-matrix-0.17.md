# 0.17 扫描与清理支持矩阵

当前普通用户版包含 23 条扫描规则：14 条既有条件清理规则，6 条既有应用只读规则，3 条新增 Windows 只读规则。系统临时文件为另外一条受构建能力限制的规则，默认全面扫描不申请系统权限。

| 新增规则 | 可信位置 | 识别与期限 | 删除影响 | 真实删除验收 |
| --- | --- | --- | --- | --- |
| windows.crash_dumps | Known Folder LocalAppData / CrashDumps | 直接子文件 .dmp；至少30天 | 历史排障资料消失 | 未执行，仅只读 |
| windows.wer_archive | LocalAppData / Microsoft/Windows/WER/ReportArchive | 直接子报告目录有有效 Report.wer（Version=1、EventType）；直接子文件 .wer/.dmp/.mdmp/.hdmp/.cab；至少30天 | 历史错误报告减少 | 未执行，仅只读 |
| windows.directx_cache | LocalAppData / D3DSCache | 直接子缓存目录内同名 .idx/.val 对；至少7天；不接纳其他后缀和更深目录 | 下次可能重新编译缓存、短暂变慢 | 未执行，仅只读 |

这些是本版保守支持的布局，并不声称覆盖所有 Windows 版本的布局。WER 未发送队列、任意自定义转储目录、厂商 GPU 缓存及个人文件不纳入。缺少匹配布局显示未支持；没有标准位置显示未发现；读取失败显示范围不完整。不能将这几种状态当作完整的零垃圾结果。

规则清理策略为 review；cleanup_validated=false 固定在内置目录和规则验证器中。后端生成计划和 Windows 删除边界再次拒绝，即使请求附带 reviewed_rule_ids 也不能解锁。当前没有 UI、环境变量或动态规则解锁入口。

## 隔离验收要求

分别记录 Windows 版本、样本来源、真实布局、年龄和时间戳、扫描清单、实际操作、再生成/后续应用运行结果以及保护文件核对。至少一个真实匹配候选；零候选不算验收通过。人工设置样本年龄必须注明，不冒充自然积累的旧文件。

CrashDumps 核对近期和其他类型文件保留；WER 核对队列、无标记目录和报告附件保护；DirectX 使用专用图形测试应用生成缓存，验证清理后应用运行和缓存再生成。三类均测试占用、权限不足、链接、目录替换、文件变化和长期排除。不得借用日常个人资料做破坏性验收。

本轮自动夹具只验证识别、年龄、保留、候选重验与删除拒绝；不能据此打开真实删除权限。原有六条应用规则继续按 [0.14 验收要求](support-matrix-0.14.md) 保持只读。
