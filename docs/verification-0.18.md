## 本轮发现并修复

- 取消所有文件后，应用组不得仍显示全选；改为依据统一选择量计算。
- 只读项目不展示无效的“退出后可清理”提示，也不提供选择框。
- 只读项目只显示只读标记，不再同时显示“需要你确认”，避免暗示人工确认可以解除后端限制。
