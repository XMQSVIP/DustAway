# 0.8 用途识别与处理支持矩阵

适用版本：0.8.0 未签名免安装预览版。仍为 14 条普通权限清理规则；[0.6 规则矩阵](support-matrix-0.6.md)、[0.7 扫描完整性](support-matrix-0.7.md)继续适用。

| 依据 | 用途类别 | 可提供操作 | 不作出的推断 |
| --- | --- | --- | --- |
| 现有元数据校验发现的用户临时文件、Chromium 精确缓存位置 | 可进一步扫描 | 查看对应规则，另行扫描、计划、确认 | 不表示其中所有文件可删，不扩展到整个配置 |
| 后端静态浏览器注册表中的 Chrome、Edge、Brave、Vivaldi 标准 User Data 路径；Local/Roaming 下 Mozilla/Firefox 标准路径 | 浏览器资料 | 定位、浏览器自身管理指引 | 不表示已安装，不删除整个配置，不读取 Firefox 配置正文 |
| Known Folders：LocalAppData、LocalAppDataLow、RoamingAppData | 通用应用数据 | 定位、原应用存储与备份管理建议 | 不猜测微信、QQ、WPS 归属或菜单 |
| Known Folders：Windows、ProgramFiles、ProgramFilesX86、ProgramData | 系统、程序或共享数据 | 定位、Windows 存储设置、应用管理 | 不建议直接删除目录 |
| Known Folders：Downloads、Documents、Desktop、Pictures、Music、Videos | 个人资料位置 | 定位，用户自行核对、备份或迁移 | 不等于所有内容可以删除；不提供删除勾选 |
| 其他位置、当前用户混合根目录、缺少用途字段 | 用途未确定 | 定位核对、通用帮助 | 不根据体积或名称猜测 |
| 节点读取不完整或读取失败 | 用途未确定 / 不完整 | 适用时定位、重新分析 | 不将零结果解释为完整无占用 |

匹配使用路径组件边界和规范化大小写；缓存先于应用，应用先于系统，系统先于个人资料。子目录继承已确认位置用途；相似前缀（例如 Documents-old）不继承。Known Folder 查询失败时不补造路径。位置表每个进程初始化时取得，修改系统重定向后请重启再分析。

最大文件排行只含已取得大小、无读取问题的文件；支持零字节、稀疏文件逻辑大小、中文长路径、跨目录硬链接（分别显示并标共享）、清理排除项（仍统计并标保留）。文件名搜索匹配字面子串，SQLite 默认大小写折叠覆盖 ASCII；中文按原文匹配，不承诺所有 Unicode 字母的大小写等价。

微信 3.x/4.x、QQ 经典版/QQNT、WPS Windows 桌面版只提供通用边界说明；菜单未经逐版本核对。不识别重复目录或迁移完成，不删除聊天图片、视频、文档备份、恢复文件或插件。

测试环境、具体通过证据和性能成绩见[验收记录](verification.md)。Windows 11、其他硬件、完整 DPI 矩阵、辅助技术、实际 Known Folder 重定向操作及真人可用性研究，未执行时不算通过。
