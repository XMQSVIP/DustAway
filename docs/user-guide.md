# 拂尘 0.25.0 用户手册

当前为小范围测试阶段，实际交付与未完成验收见 [版本记录](verification-025.md)。

## 扫描与选择

首页默认选择 C 盘，可选择其他支持的本地固定 NTFS 磁盘。开始扫描只读取本版本支持的位置，不会删除文件；空间分析的位置与垃圾扫描的磁盘选择独立。

建议项在新扫描后初始化选择，需要确认的项目默认不选。可以打开文件明细、搜索和翻页，取消需要保留的文件。查看分类、翻页和运行状态复查不会自动恢复已取消的选择。

结果分别说明扫描是否完整、是否允许清理、应用运行状态和容量是否已知。只读内容计入发现占用，不计入可选量。只有已开放但被应用运行阻止的项目才需要正常退出应用后复查；退出不能解除只读限制。

部分读取失败、中断和未知容量会明确显示，零字节不代表完整读取。复查运行状态不发现新文件；重新扫描才更新占用。

## 一次确认与结果

点击“清理已选”后，后端核验并冻结清单。确认框展示文件数、目录数、文件大小、扫描范围和内容来源；自选内容可查看路径，Windows 官方维护的估算另计。扫描范围不代表每个磁盘都有所选文件。

确认后永久删除，不进入回收站、不能撤销。取消确认保留选择与位置。核验后内容减少时会提示保留数量；执行期间发生变化、占用或无法验证的内容继续保留。

完成页区分删除、跳过、失败、结果不确定及未处理；历史保留汇总记录。文件大小不是承诺释放空间，逐盘可用空间读数还受其他程序写入影响。旧记录缺失数据时显示未知。任务状态不确定时先查询，不重复提交删除；停止不会恢复已删除内容。

## 空间分析与自选内容

分析目录排行、大文件和用途，在已读取结果中选择文件或文件夹。文件用途及小模型推测不能证明文件无用，也不会授予清理权限。受保护位置、链接、云文件与多硬链接继续保留。

自选清单支持搜索、分页、移除与父子范围合并。点击“清理已选”后核验，并与规则清理分组确认。只删除冻结清单中的文件及已经为空的目录；分析后新增文件不会被纳入。切换页面保留会话和选择。

## 专项功能

- 微信、经典 QQ 与 QQNT 附件按来源和账号分别扫描，支持分类、时间筛选及跨页选择。附件默认不选，独立确认永久删除；未知格式和受保护资料保留。
- 软件卸载调用核验过的官方卸载入口。卸载成功不表示全部残留可删；残留扫描和删除资格单独核验。
- 官方缓存工具采用固定受限操作，扫描占用不等于闲置量。零收益不自动视为失败。
- 安装版可使用已开放的 Windows 维护，按需单独申请管理员授权；免安装版无辅助组件和提权清理。

## 设置与隐私

长期排除只缩小范围；修改排除项后需要重新扫描。主题与减少动画设置不清空任务。分析索引最多占用 4 GiB，并为索引磁盘预留 2 GiB；更换索引位置会清除分析结果和自选清单。

程序不上传路径或正文，不自动联网更新规则。诊断导出包含版本、规则与汇总，不包含候选路径或排除设置；手工附加资料仍需检查个人信息。
