## 真实桌面与免安装检查

`pnpm build` 后执行 `cargo build -p dustaway --features e2e-fixture,custom-protocol` 与 `node scripts/e2e.mjs`，通过真实 Tauri、WebView2 和 IPC 验证最大化/还原，并操作专用夹具：扫描、本页取消后禁用清理、主题保存后结果与选择保留、本页选择、搜索、完整路径展开、计划确认及返回检查、执行、历史。只删除旧夹具文件；近期文件和根之外的保护文档保持不变。分页栏的几何检查确认位于窗口内，无横向溢出。

界面证据：`artifacts/desktop-details-light-0.2.png`、`artifacts/desktop-details-0.2.png`、`artifacts/desktop-e2e.png`。已人工检查浅色/深色明细截图；这不是完整键盘、屏幕阅读器或 DPI 验收。

`node scripts/smoke-portable.mjs` 使用上述最终 EXE，结果与 SHA-256 写入 `artifacts/portable-smoke.json`，截图为 `artifacts/portable-readonly-0.2.png`。实测通过：

- 原生客户区顶部间距实测为 0 px，没有原生标题栏占用；自定义最大化/还原、顶栏双击、最小化后重复启动恢复，以及关闭按钮均通过。
- 源码目录之外、含中文和空格的路径启动，仅含 EXE，不存在 helper。
- 专用程序目录被 DACL 拒绝写入；写入探针被拒绝，主程序仍能启动与只读扫描，未向程序目录创建设置或 WebView2 数据。测试结束恢复原 DACL。
- 第二实例退出，不产生第二个独立任务窗口。
- 移动 EXE 后再次启动，设置与先前读取一致，程序目录仍只有 EXE。
- Bootstrap 确认普通后端、0.2.0、8 条用户规则、system_cleanup=false。
- 直接系统 scope、混合扫描、混合准备计划和混合执行请求均返回 capability_unavailable；伪造用户计划返回 invalid_plan。拒绝前后会话 ID 和状态一致，未启动 UAC 或任何清理任务。
- 本机实际用户目录只读扫描进入 ready；未提交有效清理计划，没有删除真实用户文件。

打包脚本直接复制到版本文件夹，并通过系统 .NET 接口生成 EXE 哈希，不调用 ZIP 接口。只读目录测试仅修改专用夹具 DACL，结束后恢复。

夹具清理后的资源快照 `artifacts/resource-snapshot.json`：主程序及 6 个 WebView2 子进程，工作集简单合计 458.2 MiB，私有内存合计 263.2 MiB。这是调试构建单时点快照，工作集共享页可能重复计算，不代表发行版稳态占用、十万文件内存上限或性能保证。
