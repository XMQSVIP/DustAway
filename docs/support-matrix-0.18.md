# 0.18 支持矩阵

当前源码在此版本后又追加了办公/网盘识别及首页体验改进，现有 35 条用户规则、16 条条件清理、19 条只读。新增许可仅限钉钉 8.2.0.119 网页与代码缓存，普通首页真实闭环仍待完成，见 [首页清理验收记录](verification-home-cleanup.md)。下面保留 0.18 最初页面调整时的范围快照，不能作为最新规则总数。

本轮仅重构前端页面与展示偏好，不扩大删除范围。普通用户版仍有23条扫描规则：14条按条件可清理、9条只读。

| 规则范围 | 默认扫描 | 默认选择 | 删除能力 |
| --- | --- | --- | --- |
| 用户临时文件、Edge/Chrome/Firefox/Brave/Vivaldi标准缓存（14条） | 尊重长期排除 | 完成扫描且通过核验的建议项 | 受占用、完整性、保留期限等校验限制 |
| 微信、经典QQ、WPS（6条） | 尊重长期排除 | 不选 | 真实验收未完成，只读 |
| 旧CrashDumps、WER归档、DirectX缓存（3条） | 尊重长期排除 | 不选 | 真实验收未完成，只读 |
| 系统临时文件 | 免安装版不启用 | 不选 | 不自动提权 |
| 下载、聊天附件、文档、注册表、更新组件、回收站 | 不作为清理规则 | 不选 | 无删除入口 |

卸载后的残留仍按实际发现显示；未发现标准位置不等于未安装。只读规则无选择框，状态重查、组选择或手动传入授权字段都不能解除后端限制。

Windows三条规则的固定目录、布局、期限和未完成真实验收说明沿用[0.17支持矩阵](support-matrix-0.17.md)。应用六条规则沿用[0.14支持矩阵](support-matrix-0.14.md)。本轮隔离夹具证据与历史真实样本证据分开记录，见[0.18验收](verification-0.18.md)。
