# 首页磁盘选择与精简说明验收

日期：2026-09-30。适用于当前开发源码，尚未发布新包。

## 交付行为

- 首页默认只选择 C 盘；支持单选、多选与“全部磁盘”。C 盘缺失或不可用时保持空选择，由用户选择其他磁盘，不自动扩大范围。
- 后端只接收已登记的卷 token，验证卷身份并在垃圾目录枚举前限定范围；目录 token、任意路径、重复身份、空选择均拒绝。继续扫描现有垃圾规则，不自动启动整盘空间分析。
- 结果记录本次扫描磁盘；调整下次范围不会改写当前结果。选择全部磁盘保持旧接口兼容。
- 移除首页、分类详情、设置、分析详情中的应用内存储管理指引，删除其组件、步骤内容和专用样式。应用名称、用途依据、保留原因与原有删除保护继续保留。
- 760×580 和 1100×780 下磁盘选项、开始扫描同时可见，无横向溢出，装饰图不覆盖操作区。
