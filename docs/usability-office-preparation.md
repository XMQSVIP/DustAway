# 办公软件清理理解测试

状态：待执行，参与者 0 人。设计者自查、自动化及公开帖子不计作参与者。

安排 5 名非开发者，在隔离电脑使用可丢弃样本，不提供操作指引。采用 P1–P5 匿名编号，记录首次点击、耗时、误操作、求助、理解和原话，不记录个人账号或路径。

| 任务 | 通过条件 |
| --- | --- |
| 扫描后解释飞书/钉钉容量 | 明确这是指定缓存的发现量，不是整个应用占用或可释放量 |
| 新版本显示“目录结构已识别” | 理解可以只读发现，但未获得清理权限 |
| 应用运行且规则只读 | 不为解锁清理而退出应用；能找到对应管理指引 |
| 解释离线邮件、聊天附件与缓存差别 | 能指出需要保留的工作资料，不选择清空整个应用目录 |
| 遇到部分读取失败 | 不把未读取位置理解为没有垃圾，能找到原因 |
| 完成既有建议项清理 | 在专用样本中保留指定文件，核对一次确认并解释实际结果 |

至少 4/5 无指导完成任务；5/5 都能区分发现占用、允许清理及应用内处理。发生误判先记录具体卡点并修正，再复测；没有实际记录不补写成功数据。
