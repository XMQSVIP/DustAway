# 简洁清理与自主选择：当前支持矩阵

2026-10-01 更新：源码现为 35 条用户规则、16 条条件清理、19 条只读；新增应用许可是钉钉 `8.2.0.119` 网页与代码缓存，默认不选，普通首页真实闭环待完成。自选删除权限没有扩大。下面保留自选能力开发时的快照，最新[首页清理验收](verification-home-cleanup.md)优先。

基于 0.18.0 的开发源码，未发布新包。沿用现有视觉和普通用户权限。应用规则与[上一轮六条规则准备](support-matrix-cleanup-preparation.md)的验收门槛不变。

| 来源或范围 | 自动选择 | 用户主动选择 | 执行边界 |
| --- | --- | --- | --- |
| 已开放的建议清理规则 | 扫描完成且当前可执行时选择 | 类别、文件均可取消，支持长期排除 | 沿用期限、应用状态、身份和路径复核 |
| 未通过真实验收的规则 | 不选 | 无删除入口 | 共 21 条只读，其中 18 条为应用规则；退出应用不解锁 |
| 普通个人文件、大文件 | 不选 | 在空间分析结果中选择 | 本地固定 NTFS、普通权限、完整私有快照、一次确认 |
| 已完整读取的普通目录 | 不选 | 选择扫描时发现的后代，可取消子目录或文件 | 去重后按清单删除；最后处理已空目录，新增内容不进入清单 |
| 未完整读取的目录 | 不选 | 只能展开后逐文件选择可验证的已读项 | 不把未知子树当成已选 |
| 系统、安装、已识别核心应用数据、拂尘数据 | 不选 | 保留 | 自选不能越过保护边界；内置规则覆盖位置须走对应规则 |
| 链接、云文件、多硬链接、占用、长期排除或无法验证的内容 | 不选 | 保留 | 准备与执行再次检查，执行期间变化会跳过 |
| 卷根、用户主目录及常用资料容器本身 | 不选 | 不能删除容器本身 | 可进入后选择符合条件的普通内容 |

规则数仍为 **35 条：14 条条件清理、21 条只读**。自选是单独来源，不增加规则数量，也不将普通文件标成垃圾。

默认界面只突出已选量、简短类别摘要和清理按钮，技术信息按需展开。自选范围在确认框显示名称、路径、核验后的文件数量、目录数量与文件大小；一个确认执行混合来源。取消确认保留选择，任何来源重扫都撤销该来源旧计划和选择。清理结果与磁盘读数自动更新，无须完成外部处理任务才能结束。

真实用户希望简洁、安全；进阶用户需要决定资料价值。这里采用渐进展开与明确自选入口，安全资格继续由后端判断。以上是本次用户需求与产品判断，尚未进行真实用户访谈或试用；自动化通过不能证明所有人都能理解流程。已执行证据和未执行事项见[验收记录](verification-manual-cleanup.md)。
