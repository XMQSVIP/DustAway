# 微信专项清理 0.20.0

本轮增加独立微信区域，修复微信占用只出现在折叠的“日志与错误报告”中的问题。缓存与日志纳入普通扫描；聊天附件仍需选择账号并独立确认，分类占用与当前筛选容量分开，不能把近期附件被筛掉理解为没有占用。

## 范围与边界

- 微信 4.x：标准 Roaming `Tencent/xwechat` 日志，以及 `radium/web/profiles` 下已识别网页配置。限定 `game`、`multitab`、`webview`、`web_shell` 及其 32 位十六进制账号后缀，要求正常的 Preferences 标记、可信腾讯签名安装和逐次文件身份核验。
- 网页代码缓存：`Code Cache/js|wasm/<16位十六进制>_0`，核验 Simple Cache v5 头尾与 v9 索引标记，索引本身保留。
- 网页图形缓存：`GPUCache/index` 和 `data_0..3`，核验已识别块文件格式、版本、大小和目录位置。
- 本次发行的三条网页缓存规则均为只读。代码和图形缓存已完成独立实删及保护文件核对，但重新启动微信后尚未观察到缓存重建；已请用户在微信中打开网页，重建及功能复核完成前不添加编译期删除许可。
- HTTP 外部条目只读，共享索引/块文件显示为保留；没有类别级失效处理前不开放逐文件删除。Chromium 的响应正文读取失败可能返回错误，不能把删除任意 backing file 当作保证无影响的缓存未命中。[Chromium 事务实现](https://raw.githubusercontent.com/chromium/chromium/main/net/http/http_cache_transaction.cc)
- 历史日志仍保留 7 天、转储仍保留 30 天；没有合格历史实机样本，保持原有只读许可。
- 接收文件扩展到已识别文件头的常见文档及媒体格式；仍限定所选账号 `msg/file/YYYY-MM/`，逐文件核验当前用户归属、安装身份、目录、文件状态、排除设置和微信进程。视频目录的既有 MP4/JPG 范围不变。
- 加密 DAT、未知格式、聊天数据库、收藏、备份、登录和小程序资料继续保留。旧版 WeChat Files / 商店版布局不宣称支持。自定义账号位置须经过同一布局与归属核验。
- 微信网页规则不继承到软件卸载残留范围；新增 ProfileLayout 不得带出 Preferences、Local Storage 或 IndexedDB 的卸载清理权限。

## 操作与统计

专项入口常驻；未扫描显示“待扫描”，部分读取和未知大小不会伪装为零。微信保留占用可直接看到，展开核对具体规则和只读文件详情。勾选缓存仍进入既有准备、确认、执行、回执流程。

附件分类统计覆盖本次成功读取的全部附件，不随修改时间、关键词或分页丢失。当前筛选单独显示文件数量、容量和可选容量。点击分类、查看全部时间、翻页均不勾选文件；只读记录和已处理记录不可选。分类不是微信总占用，也不与普通扫描容量合并。

## 验证记录

证据保存在 `artifacts/weixin-special/`。测试机为用户授权的 DESKTOP-24NJTT6，使用严格 SSH 主机记录校验及 MSN 普通用户计划任务。没有修改防火墙、网络、UAC、ACL 或持久执行策略。

- 初始只读核对识别微信日志及 Radium 网页缓存，未读取聊天数据库正文。
- `gpu-delete.json`：真实删除 10 个网页 GPU 缓存文件，共 1,114,848 字节；2,789 个其他微信文件的内容摘要保持一致。
- `code-delete.json`：真实删除 1 个网页代码缓存文件，共 229 字节；2,788 个其他微信文件的内容摘要保持一致。
- 接收文件测试只创建并删除测试自己的 TXT、PDF、DOCX，不以用户聊天文件作删除样本。早期测试比较了未规范化路径而没有找到自身样本，未删除聊天附件；三个遗留测试文件经精确文件名与大小核对后清除，测试改用规范化路径并先保存自有文件清单。
- 初次运行中测试实际遇到微信已退出，断言失败；这是测试前提不满足，不能算作运行中保护通过。
- 微信重新启动后的 `running.json` 验证三条规则均返回 `application_running`；`after.json` 中代码与图形候选仍为零，不能冒充缓存重建通过。
- `received-files.json`：三个自建 TXT、PDF、DOCX 均通过格式与身份核验、排除拒绝和精确删除；2,788 个未选择文件的内容摘要保持一致。
- `probe-test.log`：0.20.0 的生产适配器在普通用户下只读发现 546 项，共 52,537,904 字节；分类汇总与总量一致，524 个加密或未知格式（29,411,270 字节）保留。22 个已识别媒体可供选择；准备和执行仍要求微信退出。没有执行聊天附件删除。
- 前端 31 个测试文件、366 项通过；核心库 56 项通过（2 项显式忽略），桌面接口 7 项通过；证据脚本 12 项、验收脚本 6 项通过，21 条应用规则投影一致。
- Windows 库主回归 155 项通过、38 项显式忽略；两个旧测试尝试固定位于 `target` 目录链接下的当前测试程序，按既有链接保护规则拒绝。将同一二进制复制到普通目录后，这两项单独补测均通过（总计 157 项通过），没有削弱路径保护。原始失败日志保留。
- 原生 WebView 夹具通过 205 项附件、100 项分页、跨页选择、预览、确认取消、来源切换，以及 1100×780 / 760×580 浅深色布局检查。夹具测试没有删除主机文件；截图见 `ui/`。

Windows 10、微信旧版和商店版未进行实机验收。Clippy 全目标及格式检查通过，构建仍有既有的前端包大于 500 kB 提示。
