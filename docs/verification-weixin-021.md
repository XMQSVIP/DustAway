# 微信专项 0.21.0 验收（2026-10-22）

## 本轮行为

微信卡片分别说明扫描状态、逐规则清理能力和本机运行状态；折叠时保留主要原因与不完整范围提示。零字节失败结果显示未知，尚未完成扫描的可清理容量显示待核验。

“重新检查微信运行状态”保留当前候选和选择，不发现新增文件；“重新常规扫描”启动原有扫描。退出微信不能开放只读项目。

附件分类是扫描时占用，本次已删除量和保留/待重新核验量分开。删除成功记录不再计入保留容量；失败或跳过不算成功删除。重新扫描清除旧选择并更新占用，分类点击和预览不自动选择。

## 许可与证据

`weixin.code`、`weixin.gpu` 仍未添加发行许可。2026-10-22 严格 SSH 指纹连接的只读检查确认测试机已有重建缓存，但未完成网页首次/再次加载验证，不能据此开放删除。

自动界面复测尝试使用已安装 UU 远程；窗口激活后仍返回最小化，截图 `FrameArrived` 超时，随后用户按物理 Escape 停止 Computer Use。本轮不再调用 Computer Use。SSH 能部署和执行普通用户测试，但这些结果不能代替微信网页可见恢复验收。没有发送消息、登录或修改安全设置。

新增 `scripts/weixin-acceptance/` 提供可重复只读预检及分阶段证据校验；生产 Engine 验收入口不能绕过删除许可。证据校验器拒绝缺失恢复、零候选、失败/未知删除结果、保护摘要变化、不同安装身份和不同网页目标。

测试期许可仅用于隔离夹具，覆盖两条微信规则的真实文件格式、Engine 选择/准备/执行/回执、取消和保护边界，不能授权生产删除。HTTP、日志、转储、加密 DAT、聊天数据库及备份维持既有范围。

## 兼容与验证

附件类别新增 `deleted_files/deleted_bytes`，旧响应缺失时不推断为零。已有接口、历史存储和确认流程保持；无需数据库迁移。`docs/current-capabilities.json` 从编译规则生成，并纳入投影一致性检查。

本轮证据存于 `artifacts/weixin-021/`。0.20 历史包和证据保持原样。

- 前端默认线程池分批运行：31 个文件、370 项通过（`frontend-batch-*.log`、`frontend-app-final.log`）。本机曾出现工作线程启动超时，重跑后通过；临时试用 vmThreads 出现模块 mock 隔离差异，不用该结果替代默认线程池验收。
- Core：56 项通过，2 项需独立环境的测试未执行。
- Windows：MSN 普通用户临时任务中 158 项通过，39 项明确要求真实应用或独立环境的测试未执行（`windows-limited.log`）。直接在 SSH 管理员令牌下运行的 ACL 夹具不符合普通用户前提，未作为通过依据。
- 补充单文件选择：代码缓存 3 选 1、图形缓存 5 选 1，各删除 1 个，保护文件摘要不变、旧计划不能重放（`single-file-receipts.log`）。这些是隔离夹具，未操作真实微信缓存。
- 测试机生产 Engine 的两条微信规则均完成只读扫描，并拒绝未验收规则的删除计划：代码缓存 1 个候选 / 229 字节，图形缓存 10 个候选 / 6,394,592 字节。两项 `deletionAttempted=false`，不能据此声称真实清理成功。
- 桌面接口层 7 项通过，包含免安装版拒绝系统与混合范围请求。证据与脚本测试 22 项通过；规则投影核对 21 条应用规则；识别库核对 256 条规则、510 个模式。全工作区 Clippy 所有目标无警告，Rust/前端格式检查、TypeScript 与生产构建通过。
