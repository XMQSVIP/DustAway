## 实现与关键行为

1. 待选位置与会话结果来源分开，改选后折叠旧结果，查看旧结果恢复位置；后端拒绝启动不替换旧会话。来源、分析时间及页生成时间有文字标记，旧响应缺新增字段时不编造。
2. 同范围更新失败保留列表 DOM、滚动及重试入口；新查询隐藏旧数据。基线按后端卷身份隔离，同卷不同目录仍比较本次运行的同一基线，失败保留带时间的上次成功空间读数。
3. 默认三条摘要，按需展开至八条；待统计不画零占用，部分大小标“已读取至少”。可信用途与统计完整性分别返回，当前层目录分为完成、未完成与待统计，不估算整盘百分比。
4. 明细显示用途、简短影响与主要操作；依据、完整路径和其他操作按需展开。只查看类别不改变勾选。指引按识别对象呈现，未知应用先给通用查找方法。结果提示先刷新磁盘空间，再回原来的保存、安装等工作核对。
5. 内存 SQLite 改用结构化列和紧凑 Windows UTF-16 核验记录；根、父链信息共享，查询只组装本页和面包屑，目录更新限于当前层。定位和细分仍重开根、父链、节点并核对身份。清理授权记录未重构。
6. 数据库页面限额 512 MiB；它不是整个进程内存硬上限。达到限额保留已提交结果，事务确保节点、身份去重与数量/大小不超前。50 万条、128 层和每页 200 项限制保留。
7. SQLite 进度回调支持索引建立与扫描中查询取消；轻量快照让索引阶段可观察。SQL 和工作线程退出后才结束停止中；取消后仍可查询部分结果。

## Release 性能

使用同机、同 Rust 工具链、同一原 0.10 NTFS 夹具，harness 分别链接已独立恢复的 0.10 与 0.11 源码。每个负载每版完整执行五轮，顺序旧/新、新/旧交替；没有与本任务编译、夹具种植或其他测试并行。操作系统缓存未清空，因此给出全部范围，不以单轮速度外推其他硬件或冷启动。

峰值来自 GetProcessMemoryInfo 的 PeakPagefileUsage，是分析 harness 进程私有提交高水位，包含随后查询；不包含 Tauri 窗口和 WebView2。每次最多查询 200 项，全部/名称搜索各五次，另测当前层及后续目录分页；p95 用最近秩法。
