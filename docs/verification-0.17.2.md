# 0.17.2 首页简化验收

本轮依据用户实际使用反馈：不应先让普通用户理解 23 条内部规则，再开始清理。

## 交互变化

- 首页主区域为“清理垃圾，腾出空间”和唯一的“扫描垃圾”按钮，旁边说明扫描不会删除文件。
- 取消首页规则总数、重复范围段落和重复底栏；磁盘空间与空间分析入口继续可用。
- 空间册、类别、空间/清单切换默认折叠，使用“查看扫描范围”按需展开；结果阶段通过“查看类别与文件”或结果入口展开。
- 扫描完成后仍提供“一键清理”，可查看明细、保留指定文件，再确认一次永久删除。
- 扫描范围、长期排除、风险项目默认不选及后端删除边界保持不变。

## 验证边界

本轮为前端呈现调整，无 Rust 业务逻辑、清理规则或数据库格式改动。Windows 新增三条规则和微信、QQ、WPS 六条规则继续只读，不代表通过真实删除验收。五名非开发者参与的可用性验证仍待执行。

桌面测试只使用显式标记的隔离调试夹具，不以个人文件进行删除测试。本轮没有重跑生产版真实位置扫描或十万文件全流程，也没有重跑未改动的 Rust 业务回归；不将历史结果标为本轮执行。历史完整清理与安全边界证据见 [0.17 验收](verification-0.17.md)，结果相关性修正见 [0.17.1](verification-0.17.1.md)。

交付目录：`artifacts/portable/拂尘_0.17.2_windows-x64/`。旧版本目录保留，切换版本时先正常关闭旧程序，再运行新目录中的程序。
