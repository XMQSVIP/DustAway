# 软件卸载与残留检查

源码新增“软件卸载”页。桌面软件读取当前用户及本机的 32/64 位卸载登记；商店应用使用 Windows PackageManager，仅针对当前用户。名称与发布者可搜索，类型可筛选，名称、登记大小和安装日期可排序。未知值保留为未知；登记大小不是实际释放空间。

## 使用流程

列表与详情显示软件自身的图标。桌面软件优先从安装登记的 `DisplayIcon` 读取图标路径和资源索引，缺失时尝试已登记的桌面卸载程序图标；商店应用读取 Windows 提供的包图标。图标以内嵌 PNG 传给界面，不访问远程图片；图标缺失、格式不支持或加载失败时显示默认图标，不影响卸载权限。

选软件 → 确认卸载并完成官方向导 → 自动检查残留 → 选择清理或暂不清理。

详情先显示卸载影响和“卸载此软件”，安装信息、独立类别能力和缺失字段放入“软件信息与清理范围”，需要时展开。卸载结果核对及只读检查自动衔接，切换页面也会继续；结果无法确认时才突出“检查卸载结果”，不会重复运行卸载器。

残留全部默认未选。“选择本页缓存”只选择当前页可清理的缓存，不包含设置、资料或已保留项目；“清理已选残留”仍需核对具体清单并确认永久删除。保留原因与处理统计按需展开。“暂不清理”或“完成”返回软件列表，不执行删除；同一会话可用“查看处理结果”重新打开。已结束且没有原内存范围的历史任务只显示简短结果入口，不占据正常操作页面。

详情将“缓存与日志”“设置”“本地资料”的检查范围和清理能力分别列出。“固定位置”表示存在明确的位置规则，实际安装归属与现存范围还要在卸载前核验；“尚未开放”表示该类别尚无独立残留删除验收；“需逐项核验”也不是可删除承诺，只有后续实际候选通过全部检查才可选择。微信当前仅有缓存日志规则，设置与资料明确显示暂不支持；WPS 设置仅覆盖两份固定加载项配置，资料仅覆盖默认文档备份。资料可能包含登录状态、浏览记录、离线内容或文档备份，默认不选。

发布者、版本、登记大小、安装日期或安装位置缺失时，保留未知值并在详情汇总未提供的信息。信息不全、残留不支持与禁止卸载分别表达，不因缺少大小或残留规则而自动禁用已核验的标准卸载。

商店应用标准卸载可能同时移除应用数据，参见 [Microsoft RemovalOptions](https://learn.microsoft.com/en-us/uwp/api/windows.management.deployment.removaloptions?view=winrt-26100)。桌面卸载向导可能另有确认或 UAC 授权。拂尘保持普通用户权限，不使用系统清理 helper，也不自动重启。程序退出码不单独代表卸载成功；失败、取消、仍有安装登记、需重启和状态未知分别展示。

商店应用同时检查系统组件身份与 Windows 的 `NonRemovable` 标记，受保护项目保留不可卸载原因。该标记通过固定的系统 PowerShell/Appx 只读查询获得，仅查询当前用户主应用包；不接受前端传入命令。读取失败、标记缺失或包版本变化时不授予卸载权限，实际移除前再次核对。标记含义见[微软商店应用排错说明](https://learn.microsoft.com/en-us/troubleshoot/windows-client/shell-experience/modern-inbox-store-apps-troubleshooting-guidance)。

商店残留另行核对数据独占性。共享容器中的应用、存在可选包/宿主等关联或系统无法完整查询时保留其数据；卸载后还会再次核对成员定义和当前用户包关系。共享成员即使没有安装登记也不能自动认定可清理。旧系统缺少查询 API 时显示保留原因，标准卸载仍按独立策略执行。

检查商店残留还会核对当前用户的相关进程：Windows 包身份匹配，或程序仍位于卸载前已核验的安装目录内，均视为尚未退出。状态读取失败则保留并说明无法核验，不显示为没有残留。拂尘不会强制结束这些进程；选择停止检查会在系统查询之间及逐条处理时生效。

桌面残留检查与删除使用全会话进程快照，再核对匹配进程的实际用户和程序名；相关进程无法查询时保留，不因当前会话看不到它而允许删除。普通用户对同用户 SSH 会话中不可访问进程的阻止已实测。商店现有 WTS 枚举在该场景漏列进程，跨会话完整性仍待修复和独立验收；商店删除许可继续关闭，现有检查不能当作完整跨会话保护的证明。

只读检查不删除文件。残留按缓存日志、设置资料和已保留项目展示，全部默认未选。可清理项经后端冻结清单、单独确认后才允许永久删除；文件变化、新增内容、排除项、链接、占用、重新安装及共享资料均保留。不提供注册表清理、强制卸载或资料备份。

## 当前能力与验收边界

**当前仅开放 Firefox 已核验程序版本 `140.17.0.1158` 的八条独立残留规则**：cache2、prefs.js、user.js、cookies.sqlite、places.sqlite、storage、bookmarkbackups、sessionstore-backups。其余规则和版本继续保留。每次仍须核验卸载前范围、安装状态、进程、排除及冻结文件身份，全部默认未选。既有普通清理的 35 条规则、14 条条件清理、21 条只读能力不变。依据及未覆盖范围见[首批六条实机证据](evidence/software/firefox-rules-20261001.json)和[书签与会话独立证据](evidence/software/firefox-history-rules-20261001.json)。

| 软件 | 只读检查的固定范围 | 残留删除 |
| --- | --- | --- |
| Chrome、Edge、Vivaldi | 当前用户的标准 User Data | 待独立验收 |
| Brave | 当前用户的标准 User Data；`154.1.96.60` 的 11 项已取得真实资料、交互卸载及测试专用逐条删除保护报告 | 尚缺真实重装拦截和正式入口/页面验证，仍未开放 |
| Firefox | 标准 Mozilla/Firefox 配置及本地 Profiles | 已核验版本的八条规则可逐项确认；其他版本和范围保留 |
| 微信 | RoamingAppData/Tencent/xwechat | 待独立验收 |
| 经典 QQ | RoamingAppData/Tencent/QQ/webkitex_cache | 待独立验收 |
| WPS | RoamingAppData/Kingsoft/office6 的日志与默认备份；Kingsoft/wps/jsaddons 下两份固定加载项配置 | 待独立验收；自定义备份和加载项代码保留 |
| 飞书 | RoamingAppData/LarkShell/aha/users | 待独立验收 |
| 钉钉 | LocalAppData/DingTalk_数字/Default | 待独立验收 |
| 百度网盘、夸克网盘、迅雷 | 现有各产品的标准 RoamingAppData 目录 | 待独立验收 |
| 商店应用 | 通过当前用户包身份与独占性核验的 LocalCache、TempState、LocalState、RoamingState、Settings；共享/未知关系保留 | 待独立验收，通用删除能力未开放 |

商店应用的 LocalCache 可能保存长期设置、资料或离线内容，按“设置与本地资料”处理，不能仅因目录名含 Cache 就当作缓存。TempState 是独立的临时缓存范围。二者仍分别核验规则和实际文件。
| 其他软件、自定义资料位置 | 可标准卸载，残留检查不支持 | 不开放 |

范围以卸载前保存的目录身份为准；共享父目录不纳入。桌面规则先核对签名及安装归属，不能只凭显示名称认领资料；核验失败显示范围未完成并保留。标准卸载若已移除目录，不再对新出现的同名目录建立权限。目录枚举逐条响应停止；所有根目录共用十万条遍历预算，读取失败和后来被保留的条目也计入，不能通过大量不可读文件绕过上限。停止或达到上限均标为不完整；未读完不能显示“没有残留”。正在进行的单次系统读取不被强制中断。启动新卸载会废弃此前残留清单。

残留已改为逐条固定规则，缓存、设置和本地资料分别声明、分别验收，不使用任意路径中的 Cache/logs 名称推导权限。新上下文仅承认卸载前捕获的独立范围；软件重新安装到同系列的其他登记位置也会阻止处理。[独立残留规则与待验收范围](software-residual-rules.md)列明 96 条声明及微信设置资料等缺口，声明不等于已开放删除。

## 任务、历史与恢复

卸载与扫描、空间分析、清理互斥。Tauri 写命令沿用请求编号及受理回执：等待超时只核对，不重复提交。软件卸载使旧清理计划和空间分析失效。

history.sqlite 新增 uninstall_reports 表，原清理记录和设置继续可用。历史页按日期合并展示，支持全部、清理、卸载筛选；清空历史同时清除两类摘要。卸载记录保存 30 天，不持久化卸载命令、安装路径或残留文件明细。恢复只核对软件身份，不回放卸载或续删；上次的内存残留范围失效后不能直接重建删除授权。

启动器提前退出而仍有安装登记的任务，也会在重开程序后保留核对入口。恢复后即使核对为已移除，页面会明确说明上次卸载范围未保留，不再自动扫描或展示不可用的“检查残留”按钮。

每次残留扫描生成独立的清单标识。重新扫描会作废旧选择、页码和清理确认；很快完成的扫描和迟到的旧请求也不会沿用旧清单。所有候选只读时，任务提示所有项目已保留，不再要求选择清理。

退出停止跟踪后，迟到的后台进度或结果不能覆盖已保存的中断记录。后台异常会进入待核对状态，撤销本次残留权限；恢复不自动重试。残留处理结果单独列出“未处理”：指已确认选择中尚未开始的项目，不计入删除量。在途文件操作的结果尚未保存时列入待核对，其余未处理项目继续保留。清理前后都保存进度，写入失败即停止后续操作；历史只保存数量，不保存删除清单。

任务与历史分别显示标准卸载结果和残留处理状态。软件已经核对移除、但残留处理意外中断时，仍显示“标准卸载：已核对移除”和“残留结果待核对”，保留已知的实际删除数量。重新核对仍只查询安装状态，不会重新运行卸载或继续删除；旧记录没有明确卸载结果时继续显示待核对。

## 验证

```powershell
pnpm build
pnpm exec vitest run src/test/software.test.tsx
cargo test -p dustaway-core --test software --locked
cargo test -p dustaway-windows software::tests --locked
cargo test --workspace --locked
cargo run -p dustaway-windows --example software_inventory --locked
# 软件页面原生 IPC、布局与模拟流程；绝不调用本机卸载程序
cargo build -p dustaway --locked --features e2e-fixture,custom-protocol
node scripts/software-desktop-check.mjs
# 纯内存残留候选：资料确认、焦点、统计与共享保留，不执行实际文件删除
node scripts/software-desktop-check.mjs --reliability --residuals --output-dir artifacts/software-residual-ui-verification
```

software_inventory 仅输出数量和来源读取告警，不执行卸载。桌面脚本必须通过后台 fixture 标记检查后才能操作。已在独立的闲置 Windows 11 电脑上完成专用 EXE 的 45 项真实后端检查、MSIX 标准卸载闭环，以及 MSI 真实移除和跟踪中断后的恢复核对。第二轮新增 MSI 样本已补齐人工确认与完整跟踪、待重启状态下禁止残留检查及恢复保护；随后由用户实际重启电脑，原任务复核为已移除，未重放卸载或重建残留删除授权。另只读核验 121 个主应用包的移除策略。UAC 人工取消验收通过：卸载器未启动、安装登记保留、残留检查被拒绝，临时提示策略已恢复。第三方产品残留删除仍未完成，不应使用开发机已安装软件验收。专用样本工具见 [验收样本说明](../scripts/software-acceptance/README.md)，它们不授权真实产品目录删除。

第三轮验证了不存在专用包身份的真实系统错误，以及闲置电脑上的模拟软件页面、丢失回执后的超时核对和 WebView 重连。重复请求保持同一任务，历史没有重复记录。随后补测原生退出提示：用户取消退出后任务继续，确认退出后恢复同一待核对任务，没有重复卸载。最后的页面断言因脚本混淆正常退出与异常中断文案失败，修正后只重新打开同一保存任务，页面与残留保护检查通过；原失败日志保留。各阶段证据与限制见验收记录。

Firefox ESR 140.17.0 已在新建测试配置上完成官方交互卸载和只读残留检查。原完整测试因占用文件属性读取的错误断言失败，记录保留；另以新的测试专用上下文补测，删除一个 16,563 字节的真实缓存文件，资料与共享父目录不变，排除、变化、占用、硬链接、新增内容及部分扫描保护通过。重装后原测试 Cookie 与本地存储可读取，测试安装已移除。补测没有恢复生产授权，不表示完整卸载删除流程、整个目录或设置资料规则已通过；该阶段尚未开放生产残留删除，后续六条独立许可见上方当前能力说明。

随后补齐普通版拂尘的真实页面流程：确认框及官方向导完成后，使用原进程中的同一任务和卸载前上下文，通过页面重新核对并只读检查 193 条残留，显示部分位置保留；所有候选未选且不可清理，历史只有原任务，实际残留删除为 0。人工确认早于自动化开始信号，因此改用连接原运行实例的接续检查；原驱动未完成和不可用的调用计数均如实保留，不视为单脚本全程通过。这次没有重建权限、再次卸载或删除残留。

运行桌面模拟测试后，用 `cargo build -p dustaway --locked --features custom-protocol` 恢复普通调试程序。模拟程序只用于测试，不作为交付包。

原生执行依据 [ShellExecuteExW](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/ns-shellapi-shellexecuteinfow) 与 [PackageManager.RemovePackageAsync](https://learn.microsoft.com/en-us/uwp/api/windows.management.deployment.packagemanager.removepackageasync?view=winrt-26100)。商店入口仅枚举 Main 包，不提交 AllUsers 或预配包操作。系统移除策略仍由 Windows API 执行。
