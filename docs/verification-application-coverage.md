- 继续复用候选 ID、选择、计划与报告。身份、父链、链接、云文件、排除项、占用及执行前复核保持；前端没有任意路径、命令或许可入口。不迁移数据库，不改历史报告格式。

## 原始失败与保留边界

- 本机实际应用数据只读，不提交任何删除或官方整理。新规则的隔离夹具验证不等同于真实 VS Code 使用验收。测试机未核验到可用 VS Code / Insiders 安装，不安装软件制造通过条件。
