## 实现

- 分析页底部直接展示统一已选汇总、“清理已选”和可选的“查看已选”。自选内容与规则选择共同进入一次冻结计划；混合来源在操作区和确认框中分别说明。
- 准备清单留在分析页，沿用操作标识与停止准备机制。统计未知、统计失败和零字节空目录均可进入最终核验；核验为空不打开确认框。只有确认永久删除后切换任务页。
- 取消确认按钮统一为“取消”。核验或停止期间保留入口节点；取消、停止和失败后恢复入口焦点，并保留列表查询、分页、滚动和选择。重复点击不会启动第二次准备。
- 文件名打开详情，目录名进入目录，目录保留一个“详情”入口。列表只留短用途和直接可见的保留原因；系统设置、定位、长期保留收进详情的“更多操作”。
- 用途、最小大小等集中在“筛选”，关闭不重置条件；显示已应用数量，清除筛选保留名称搜索。垃圾文件侧页的批量长期保留默认折叠，未保存草稿仍直接提示。
- 每页只保留一份主要已选汇总。完成页隐藏任务栏和重新扫描按钮，详细原因与类别明细统一放入“查看清理记录”。返回首页仅结束查看，保留磁盘选择、结果及历史。
