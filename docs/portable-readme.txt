微信专项清理
清理页常驻“微信专项清理”：显示缓存与日志已扫描容量、可直接清理量、已保留容量及原因。
微信 4.x 标准日志与已识别 Radium 网页缓存纳入常规扫描；聊天附件需选择账号后单独扫描。
网页响应缓存、代码缓存、图形缓存及历史日志/转储当前只读。代码和图形缓存实删已测试，
重建及功能复核尚未完成，不能因为退出微信就获得删除许可。

“整理微信聊天附件”按图片、视频、语音、接收文件、未知格式汇总；分类容量包含近期文件。
默认仅列出修改超过 30 天的附件，可选 90 天、180 天或全部时间；不代表消息发送时间。
支持分页、预览、跨页选择与查看全部已选；查看和筛选不会勾选文件，附件初始不选。
分类显示扫描时占用；本次已删除量不再计入保留容量，当前剩余量需重新扫描。
运行状态复查保留原候选和选择，不查找新文件；重新扫描会清除旧选择。
接收文件限所选账号 msg/file/YYYY-MM 下通过文件头核验的常见文档、图片和音视频。
原有 msg/video/YYYY-MM 下 MP4、JPG 范围保留。自定义账号位置必须通过布局和归属检查。
加密 DAT、语音专用目录、未知格式、聊天数据库、收藏、备份、登录及小程序资料继续保留。
准备与执行前需正常退出微信，不会强制结束进程。删除后本机聊天附件可能无法再次打开，
不能保证重新下载。当前状态、结果说明及远程验收限制见 verification-weixin-0211.md；历史见 verification-weixin-special.md。
经典 QQ 和 QQNT 的目录与格式范围维持原有许可，见 verification-qq-attachments.md。

常规与系统清理
规则数量由编译规则导出，见 current-capabilities.json。
默认扫描 C 盘，可多选磁盘；仅检查支持位置，不把个人下载或文档自动当作垃圾。
用户和 Windows 标准 Temp 保留最近连续 24 小时；Windows Temp 属于安装版系统能力。
已扫描占用、可直接清理、已保留与本次已选分开显示；保留明细只能查看，不能进入删除清单。
未知大小、无权限和未完整读取不显示为零；扫描、准备及删除前复核文件和排除设置。

免安装版提供当前用户清理、缩略图/DirectX 官方维护及 Windows 存储设置入口。
Windows Temp、IIS 历史日志和系统官方维护需要安装版的独立提权组件，首次系统项目不预选。
Windows 官方估算不与逐文件大小相加；估算变化与磁盘空间变化不是实际删除字节数。
未确认结束的操作记录为待核实，不自动重试。实际支持范围见 system-cleanup-acceptance.md。

uv、Go、Yarn Classic、ccache 使用固定官方工具命令，按项确认，不计入逐文件已选量。
pnpm 等缺少可执行边界证据的保持只读。不自动下载、升级工具或结束用户应用。
应用按可信安装、布局、组件与格式核验；软件版本是验收背景，更新后必须重新扫描。
不能确认来源、格式、运行状态或文件身份时保留。详情见 cleanup-compatibility.md。

程序在本地处理，不上传文件名、路径或内容，不在线下载清理规则。
历史保留 30 天；长期排除、界面主题和帮助入口在设置中。
完整性校验见 SHA256SUMS.txt；许可证与依赖见 LICENSE、THIRD-PARTY-NOTICES.txt、inventory.json。
