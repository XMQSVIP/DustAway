# 0.13 普通用户试用

状态：**人工可用性待验证**。没有参与者记录，不报告完成率。由项目所有者安排五名非开发者，每人约 20 分钟，使用独立账号和标记合成夹具；同意后才录屏，不使用唯一个人资料测试删除。

主持人只描述任务，不提示按钮；求助后完成单独记录。沿用 [0.12](usability-0.12.md) 的空间不足、混合状态、选择取消、部分成功与回原任务核对流程，并加入：

| 任务 | 要观察的行为与理解 |
| --- | --- |
| 一类文件失败，找到原因 | 从结果入口直接看到失败文件，能说出下一步，不将所有候选误当成失败 |
| 两个以上类别有异常 | 选择相应类别；关闭明细后继续原列表，不重复寻找；不混入其他结果状态 |
| 正常保留后结束 | 理解保留不等于失败或已删除，刷新空间后回到原保存/安装任务，不为清零而重复扫描 |
| 占用、变化或缺少原因 | 理解仍要核对，必要时重新扫描，不直接重删旧计划 |
| 查看特定浏览器指引 | 只核对缓存选项，不全选资料、不误删用户目录；查看与关闭不改变勾选 |
| 旧报告明细不可用 | 理解历史只有统计，不把新扫描文件当作旧执行证据 |

每人记录匿名编号、系统/缩放、经验、独立/帮助/未完成、耗时、原话、错误、求助和重扫次数。区分主持提示、界面缺陷及不理解保留原因。

验收目标：至少四人无提示完成扫描—判断—确认—复核，所有参与者区分只读结果与可删除候选。删除范围误解须先修正再复测；五人样本不能外推为市场完成率，自动化不能代替人工观察。
