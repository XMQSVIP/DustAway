## 本轮改动

- 首页对运行状态未知的清理项提供独立复查入口，包括没有候选文件的情况；运行中、位置缺失、尚未开放、检查不完整与正常空结果分别说明。
- 复查保留原选择，移除按钮后将焦点恢复到结果区域；失败可以重试，旧成功提示先清除。复查不发现新文件，提示需要重新扫描的场景。
- 浏览器多配置扫描仅在全部相关缓存目录缺失时报告位置不存在。单个空缓存目录不再遮蔽其他配置的可清理结果，无法读取的配置仍记入覆盖问题。
- Firefox 支持 UTF-8 BOM 配置、标准数字编号 Profile 节及大小写重复路径去重；绝对路径和非标准节不扩大扫描范围。
- 保持现有规则许可、删除核验、数据库与 IPC 接口；目录存在不作为应用已安装的证明。百度三项缓存保持只读，钉钉精确版本许可不变。
