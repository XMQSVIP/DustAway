# 简洁默认清理与进阶自主删除：实现和验收

日期：2026-09-30 UTC。基于 0.18.0 开发源码，Windows x64、普通用户权限、本地 NTFS。未发布新安装包。本记录中的实际删除全部针对工具创建的专用合成资料；真实应用删除验收、真实用户访谈和试用均未执行。

## 实现结果

- 普通流程：主动扫描，自动选择已开放且当前可执行的建议项，清理已选，一次永久删除确认。类别、应用能力和技术原因默认折叠，磁盘空间在任务结束后自动刷新。
- 进阶流程：空间分析提供文件与目录选择、本页选择、子项取消、半选、跨页保留及长期排除。自选和规则候选共用确认，允许没有垃圾扫描的自选计划。
- 冻结清单：只接受分析会话与节点 ID，由后端私有索引重建并核验文件身份、父链、完整时间和属性。按身份去重、精确计量，文件与目录分别统计。
- 删除边界：普通权限、本地固定 NTFS、固定保护范围；应用验收开关不变，不能用自选入口绕过。按清单逐文件删除，再自底向上处理身份一致的空目录；没有递归删除。
- 恢复兼容：沿用单次计划、请求核对与持久意图记录。来源和对象类型进入内部 ID，个人路径不写入历史意图；旧报告字段使用缺省值，无数据库迁移。取消或中断不续删，待定结果为不确定。

目录时间会被本次子项删除改变，因此执行目录删除时比较身份、创建时间、属性和父链，并交由 Windows 拒绝非空目录；文件仍比较完整时间快照。未知或无法检查的项只会保留。

## 资源与响应记录

完整桌面夹具包含 **100,002 个文件**。该次只读分析墙钟约 18.45 秒，查询约 27.3 毫秒，取消约 546 毫秒；这是本机合成样本结果，不是其他电脑的速度承诺。实际删除只选择该夹具的少量明确样本。主进程与 WebView2 的单时刻资源记录附在同一 JSON，不把工作集相加称为独占内存。

分析仍限制 50 万条、128 层，分页最多 200 项。分析库与自选清单分别限制 SQLite 页面数量，不把这些限额称为整个进程内存上限；清单临时排序也在内存中。准备过程按项核验并检查取消，取消请求不等待持有索引锁的准备线程。

`artifacts/manual-large-preparation.log` 的三项核心测试通过，其中准备取消在 **100,000 个文件节点**的合成索引上执行：进入私有记录核验后取消，断言两秒内退出、没有完成清单。它验证索引和取消协议，平台核验为合成实现，不冒充十万次真实文件句柄操作的性能。前端还覆盖停止请求后迟到的计划响应，选择保留且确认框不重新出现。
