# 0.16 非开发者试用

状态：**人工可用性待验证**。未安排或代填任何参与者。

使用专用演示数据招募五名非开发者，覆盖办公、开发和设计情境。主持人说明“为保存或安装腾出空间，保留仍需要的资料”，不先讲按钮位置，不要求删除日常数据。

1. 找到由许多小文件组成的大依赖目录，说出其用途、影响和需要保留的数据。
2. 按用途找到一个模型、视频或备份大文件，打开处理与复核。
3. 在没有已识别匹配时找到未归类项目，解释“未归类”不等于没有占用。
4. 面对部分分析，查看待补充目录；没有可用目录时选择较小范围，不反复重扫同一受阻位置。
5. 进入目录、打开面板或查看清理类别后返回，核对条件和位置没有丢失，并回到原工作验证。

记录首次找到相关项目的时间、目录点击次数、求助、无效重扫、误认为用途等于清理权限、重复累计大小及返回位置丢失。只记观察事实和原话，不收集私人路径、文件内容或账号。

目标至少四人无需提示完成；所有人都能说明用途不是删除资格、父子目录大小不可直接相加、部分排行不是完整磁盘。失败保留记录，不能从样本剔除。与0.15使用相同任务资料比较，不用规则数量或删除量代替成功率。
