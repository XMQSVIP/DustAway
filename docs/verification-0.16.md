## 性能

沿用专用标记目录`artifacts/dustaway-analysis-bench-0.10`。相同规则库、工具链和harness，旧/新交替各五轮十万与五十万负载，另测大量目录、中文长路径、硬链接和取消。运行期间本任务未并行编译、种植或执行其他测试；同机其他工作不可控，已在元数据中说明。OS缓存未清空，不代表冷启动或其他设备性能。
