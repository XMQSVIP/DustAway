# 0.17 验收记录

版本：0.17.0。日期：2026-09-28。环境：本机 Windows x64、Node 24.12、pnpm 10.30.3、Rust 1.97.1。本文区分工程夹具验证与真实产品验收，不沿用旧版本截图或发行包哈希。

## 本轮实现

- 启动不扫描；点击全面扫描检查全部未排除的普通用户规则，旧扫描偏好不缩小范围。当前为 23 条用户规则，另有一条受构建能力限制的系统规则。
- 扫描与清理选择分离；建议项只在新扫描结束时初始化一次，需确认项只接受本次手动类别或文件选择。切册、切视图、分页、刷新状态不恢复取消选择；恢复旧任务不继承删除授权。
- 三个跨册结果入口、文件删除影响、一次永久删除确认、实际删除/保留/失败与磁盘空间变化。扫描展示当前类别、已检查数量与耗时，完成前不开放清理。
- 后端 Selection 新增 included_ids、reviewed_rule_ids；显式文件必须属于当前候选，需确认规则缺少人工选择标记时拒绝。仍使用一次性计划，不提供任意路径删除。
- CrashDumps、WER ReportArchive、DirectX D3DSCache 三条新规则仅识别固定范围并只读展示。扫描和候选重验使用原有固定路径、句柄身份和文件时间检查；计划与删除边界继续拒绝未验收规则。
