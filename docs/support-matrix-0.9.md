## 识别与保护

本机三款主程序的离线签名和程序版本识别已实际执行，证据见 application-support-0.9.json。离线证书验证不保证取得最新吊销信息；验证失败或发现多个不同的有效安装时，拒绝判定支持。

微信映射缓冲、配置、聊天记录和附件；QQ Network、Local Storage、Session Storage、数据库、聊天媒体；WPS 备份、恢复文件、离线云文档、插件和安装资源均不纳入新规则。支持检查与只读扫描不读取这些文件正文。

## 开放每条规则前的必要证据

1. 在隔离 Windows 环境中记录实际程序版本、签名、布局和测试步骤；不复制日常账号资料。
2. QQ 实际生成目标缓存，退出所有相关组件，清理后重新生成；测试登录状态与持久网页数据保留。
3. 微信/WPS 清理过期诊断文件后可正常启动、继续产生日志，合成资料和配置保持；转储保留期限验证通过。
4. 运行中、重新启动、版本变更、未知状态和路径变化均拒绝；受保护文件内容、修改时间一致。
5. 将逐条原始证据和准确适用版本纳入仓库审阅后，才修改静态 validated 标记。当前没有 UI 或环境变量开关。

未执行真实应用验收的原因：当前未发现可用的隔离 Windows 虚拟机/沙箱或专用测试账号。不会在日常微信、QQ、WPS 配置中进行删除、强制退出或登录态实验。
