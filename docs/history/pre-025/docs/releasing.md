## 当前交付：0.18.0 免安装预览版

```powershell
pnpm install --frozen-lockfile
pnpm check
cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings
pnpm test:e2e
pnpm portable
```

`portable` 生成依赖声明，以 `tauri build --no-bundle` 构建默认用户版，再执行 PowerShell 打包。它不运行 NSIS、安装 WebView2 或准备 helper。

输出文件夹为 `artifacts/portable/拂尘_0.18.0_windows-x64/`：只有 `拂尘.exe`、LICENSE、第三方声明、依赖清单、说明和逐文件校验清单。不生成 ZIP，不嵌套随机目录。再次构建前先退出程序；同版本已知文件会更新，若存在额外文件或子目录则停止，避免夹带未知内容或删除用户文件。此前 ZIP 作为旧产物保留，不再更新。

默认构建不启用 `system-cleanup` 或 `e2e-fixture`；生成的 release 不包含调试夹具后端。程序使用本机 WebView2 Runtime，缺少时提示用户访问微软官方页面，不随包塞入固定运行时。

## 验证与更新

- 在源码目录之外、中文和空格路径、移动目录及只读程序目录测试启动；确认无 helper、无 UAC，前端由 EXE 本地资源加载。
- 检查普通用户运行、重复启动、退出停止与设置沿用。缺少 WebView2 的真实系统单独验收。
- 真实删除只用受保护的调试夹具或可还原 VM，发行版在开发主机仅作只读启动/扫描验证。
- 记录实际通过结果、EXE 校验值、签名状态、环境和未完成事项，见 [验收记录](verification.md)。
- 新增 Brave / Vivaldi 规则必须先通过 `scripts/browser-validation.mjs` 的真实稳定版隔离配置验收：三类缓存生成、清理、重建及保护数据核对。夹具单元测试不能替代这项门槛；程序来源、准确版本和哈希随验收证据保留。

更新不依赖安装器：退出旧版后运行新文件夹中的 EXE。数据目录及应用 ID 保持不变。程序目录可只读；不可把程序目录可写作为运行前提。

当前为未签名预览版。`scripts/sign.ps1` 保留为未来受控发行签名入口，使用证书存储和 SHA-256 时间戳，不保存私钥或密码。以后签名时必须先签 EXE，再复制到交付文件夹并重新生成哈希；哈希不能代替签名或证明来源。

## 保留的实验安装构建

```powershell
pnpm bundle:installer
```

此命令显式启用 `system-cleanup`，准备 sidecar 并合并 `tauri.installer.conf.json`，恢复每机器 NSIS 安装。当前免安装交付不执行此命令。系统辅助进程仍要求 Program Files，真实 UAC、管理员凭据与安装升级验收留在独立实验路线。

中文产品名改变可能影响由名称派生的旧安装器元数据。没有执行旧 NSIS 到新中文产品名安装包的升级验收，不承诺该迁移；内部应用 ID 与普通用户数据库位置保持原值。

## 0.9 新增应用规则门槛

六条新增规则的 `validated` 均为 false，当前发行说明必须注明只读，不能宣传已经支持微信/QQ/WPS 直接删除。逐项状态见 [支持矩阵](support-matrix-0.9.md)。发布前确认默认关闭、运行中阻止、退出后仍受验收限制，且 Windows 删除入口拒绝绕过计划。

解除任意一条限制前，应在独立 Windows 环境用已验证版本和专用测试账号完成生成、删除、重建或生成新日志、正常启动、登录/网页持久数据及非目标文件保护验证。不得把日常账户资料用于删除测试，也不能用单元夹具代替实际应用证据。


## 0.11 分析优化发布核对

对比包必须独立恢复构建 0.10，保留其源码与程序哈希；本版默认仍不启用 system-cleanup。不要只凭分析条数减少宣称省内存：五轮对比须达到相同条数上限，同时报告完整耗时、查询 p95、取消与 WebView2 的独立成本。

性能目标与原始证据、视觉检查及未验证环境见 [0.11 验收](verification-0.11.md)。人工可用性未开展时明确写待验证；未通过真实应用验收的六条规则持续只读。
