# 五名非开发者试用脚本（待执行）

实际参与人数：0。本轮不以开发者自测或自动化代替真实用户试用。沿用[办公通信试用脚本](usability-office-preparation.md)，增加以下任务；使用演示或专用测试资料，不要求删除日常网盘/下载文件。

| 参与者场景 | 任务 | 观察点 |
| --- | --- | --- |
| P1 普通办公用户 | 扫描后找出百度网盘占用，说明现在能释放多少 | 是否区分发现占用、已选容量与只读 |
| P2 夸克用户 | 查看空缓存和未完成读取两种结果 | 是否错误理解为软件未安装或没有任何占用 |
| P3 迅雷用户 | 在空间分析遇到大 .xltd 文件，描述下一步 | 是否回原应用核对任务，而非直接删或改名 |
| P4 经常离线工作者 | 查看持久存储与下载目录的解释、应用指引 | 是否理解离线价值，是否误把已同步当成删除许可 |
| P5 轻度电脑用户 | 对运行中的只读项目作决定，再清理一个现有夹具类别 | 是否无效退出应用、误计只读容量；一次确认是否清晰 |

每人记录原话、操作路径、完成时间、求助点、误判/误操作及放弃原因；不采集账号、文件正文或遥测。让参与者解释“发现占用”“允许清理”“应用内处理”的区别，再记录其是否知道外部操作不计入拂尘删除量。不预填满意度或成功率。

若出现只读项目可被理解为可删除、部分读取被理解为完整零结果、.xltd 被理解为必然无用，优先修正文案与路径，不通过增加规则数掩盖问题。
