# 0.25.0 完善路线

目标：面向办公与日常用户交付可复核的小范围测试版，保留永久删除和现有安全边界。

1. 统一当前能力、文档、编译投影、操作证据台账及本地/CI 检查。
2. 统一选择与确认统计，完善范围、保留原因、结果及键盘/窄窗口体验。
3. 验证已有常用清理流程；独立审阅微信代码/图形缓存和钉钉/ToDesk 日志四条候选。缺少真实恢复证据继续只读。
4. 按需加载大型页面、减少重复查询，测量大规模分析与资源上限，交付两种候选包。

当前人工试用和功能观察尚待外部参与者，不能用自动化替代。逐阶段实际状态见[验收记录](verification-025.md)。

后续再评估可恢复删除、设计/开发人员专项和正式签名；本轮不引入模型自动删除、后台清理或在线规则。
