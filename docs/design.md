# 拂尘：雕塑式空间整理

当前界面将已确认的 HTML 原型应用到 React / Tauri 桌面程序。核心形象是钴蓝环形雕塑与杏橙球体，冷白背景、非对称构图，四个导航和主要操作始终有明确文字。原型仍在 `prototype/index.html`，只使用模拟数据；桌面应用读取真实任务、文件与磁盘信息。

## 布局

首页以“把空间，慢慢展开。”和透明雕塑形成主视觉。底部一条操作区依次提供实际可用空间、安全说明、查看扫描范围与“开始扫描”。启动不自动扫描，检查范围按需展开。后端未提供总容量，因此首页不绘制虚构的磁盘使用比例。

结果页撤下大雕塑，将位置留给分组和文件选择。宽窗口右侧保留选择汇总与清理按钮，窄窗口使用固定底部操作区。汇总来自当前真实选择，不把发现量作为可释放空间。文件明细保留原有侧页、取消选择、关闭及焦点恢复。

空间分析保留位置选择、只读扫描、大文件/大目录/目录浏览、搜索、用途过滤、分页与详情。历史按日期展开清理回执。设置分为外观、保留清单和帮助与关于。帮助与保留范围也可从页脚直接进入。

## 色彩与动效

浅色背景 `#EFF2F0`，表面 `#FAFCFB`，正文 `#1C2724`，钴蓝 `#2D4BE9`，杏橙 `#F6B58F`。深色背景 `#151E22`，表面 `#1F2C32`，正文 `#EFF2E9`，辅助蓝 `#AABAFF`。使用本机中文字体与 Segoe UI，容量数字使用 Bahnschrift。

雕塑主体保持稳定，旁边三个小块分别做缓慢起伏与轻微转动。图形使用现有透明素材 `src/assets/space-sculpture.png` 和 CSS 分层裁切，没有图片矩形底色，也不依赖联网或 WebGL。扫描阶段小块节奏略快；完成、停止、状态不确定以及设置缩略图静止。系统减少动效或应用内减少动效均会关闭动画。

扫描进度不伪造百分比，清理进度使用后端已处理项/总项。装饰不接收键盘焦点，按钮不依赖悬停。默认 1100×780、最小 760×580，列表可滚动，主操作留在可视区域。

## 实现与恢复

`useAppController` 和清理决策模型继续提供业务状态；`CleanupDecisionPanel` 组织阶段和结果，`HomeStorage` 展示实际可用空间，`LayerScene` 管理装饰层，`sculpture.css` 覆盖旧视觉。保留现有 `start_scan → prepare_cleanup → execute_cleanup` 后端确认机制、规则限制和排除设置。

修改前源码本机备份：`artifacts/before-sculpture-application.zip`。旧免安装程序保留在原目录，新视觉程序单独交付到带“雕塑设计版”的目录。原设计记录见 [整理台设计](design-desk-0.18.md)，本次检查见 [雕塑设计应用验收](verification-sculpture.md)。


## 当前选择交互

首页磁盘读数仅对应扫描磁盘，默认 C；多盘逐项展示，超过三盘折叠。分析目录与首页关注磁盘分别维护。磁盘列表加载、失败、没有可用磁盘和未选择有独立状态。

文件详情保留现有侧页视觉，只提供名称、位置、大小、简短用途、勾选与保留原因，完整依据折叠。关闭回到原列表；删除持续核对状态和独立采样步骤。勾选与清理页共用同一份选择，自选清单位于独立的“自选文件与文件夹”折叠区。“查看已选”是页面导航，不是再次加入或确认。

分析页底部直接提供统一选择汇总和“清理已选”，无需先导航到清理页。准备清单及取消确认留在原页；仅确认永久删除后进入任务页。入口按钮保持同一节点，停止或取消后恢复焦点和原列表位置。列表中文件名打开详情、目录名进入目录；目录另有“详情”入口。用途及最小大小条件收在“筛选”，低频操作收在详情的“更多操作”。

摘要等待时显示正在统计，失败显示未知与重试。扫描记录的预览量与最终冻结计划分别呈现，任何选择变化废弃旧确认计划。文件大小和文件夹数量分开计算，零字节目录也有清理入口。

## 按用途直接选择

主结果列表按用途显示建议分类及复选框，不再用“查看并调整”包住全部结果。可自行选择、已保留和自选清单分别展开；用途内直接列出规则，不再套应用层。技术信息按需渲染，避免在初始结果中堆叠版本、识别及验收说明。

宽窗口右侧保持已选汇总与唯一清理按钮，窄窗口底部提供同一统计和操作。大小来自统一选择估计，数量分开表达文件与文件夹。完成页以结果为中心，“完成”仅结束查看并返回首页，不改写后端记录。后台任务状态未知与已结束但部分文件结果未知仍分别处理。

完成页不显示底部任务栏及重新扫描按钮，原因和类别明细从“查看清理记录”进入。无可清理内容时也可返回首页；保留原磁盘选择及稳定高度布局。批量长期排除入口默认折叠，有未保存草稿时仍显示数量和保存入口。见[清理体验减法验收](verification-cleanup-simplification.md)。
