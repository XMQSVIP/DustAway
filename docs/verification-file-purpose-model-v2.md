# CPU 用途模型 v2 验证（2026-10-26）

当前模型 `purpose-nb-v2-b213b433026f`，特征版本 2，86 项词特征，14,338 字节；v1 为 18,412 字节，模型体积减少约 22%。应用版本仍为 0.24.0。本轮只优化训练、推理和开发评估，没有改变分析 IPC、清理权限、清理规则或选择行为。

## 变化及可复核结果

v1 会将扩展名重复计入文件名称信号，也可能把远层 Cache 目录的含义传播到资料子目录。v2 使用完整目录名及单独扩展名、近层上下文、学习到的资料目录冲突和保护扩展名拒绝条件；中文目录与数字轮转日志的特征覆盖也得到补充。目录自身名称只计一次，分别采用目录/文件分差门槛（1.0/2.5）；这些是开发阈值，不是经过校准的概率。

训练样本从六个虚构软件组、144 条增加为九组、225 条；新增 81 条人工编写的中文及轮转日志等记录，没有读取用户文件。每个特征至少在两个训练组出现，同一组每个类别/特征只贡献一次。跨组重复支持、alpha=0.5 平滑和无区分力特征过滤均由训练折内重新计算；原 test 集不进入权重。训练行排序稳定，重复标注无法靠同一软件的大量文件反复加权。

以下使用**完全相同的测试记录**比较 v1 二进制与 v2。v1 在修改实现前运行，其输出与测试集指纹保存在 `models/file-purpose/baseline-v1.json`；v2 运行实际 Rust 推理器，输出在 `models/file-purpose/validation.json`。不允许更新测试集后沿用原基线分数。

| 合成开发样本 | v1 | v2 |
| --- | ---: | ---: |
| 原有 56 条：正确分类 | 33 | 39 |
| 原有 56 条：未知/保护项正确拒绝 | 16/16 | 16/16 |
| 新增 66 条：正确分类 | 21 | 30 |
| 新增 66 条：未知/冲突项正确拒绝 | 23/33 | 33/33 |
| 新增 66 条：错误缓存/日志/临时文件推测 | 10 | 0 |

v2 在两集合共 122 条中正确分类 69 条，正确拒绝全部 49 条未知/保护项，另有 4 条有类别但证据不足而拒绝。拒绝仍保留为未知，不填充假分类。主要改善场景包括中文的缓存、日志、临时、文档、配置目录，以及 Cache/资料、temp/备份、源码/缓存等冲突路径。

九折软件组留出验证：只对训练组逐组留出，词表与权重各自重训；225 条中 173 条正确分类、52 条拒绝，覆盖率 76.9%，这些折中未观察到错误分类。报告保存每组统计。调整了特征、参数及拒绝条件，因此以上全部属于**开发评估**；合成记录共享命名习惯，不代表独立真实准确率或删除安全性。未做真实机器数据评估、概率校准或清理验收。

## CPU 与文件体积

同一机器 Intel Core i5-10400、同一份 v1 的 200 条合成记录循环推理，共十万次/轮；预热后交替测量两个 release 二进制，各三轮：

| 版本 | 三轮耗时（ms） | 中位数（ms） |
| --- | --- | ---: |
| v1 | 273.90、280.64、277.20 | 277.20 |
| v2 | 277.56、273.75、274.79 | 274.79 |

速度基本不变，约 2.75 µs/条；该基准不包含模型初次加载、磁盘扫描或界面查询。v2 最终训练单次实测约 11.03 ms。独立 CLI 为 648,704 字节（新增解释、独立评估与分组验证功能），模型仍只有 14,338 字节。测量细节与命令保存在 `artifacts/file-purpose-v2/performance.json`、`benchmark.mjs`；v1 副本在同一 artifacts 目录保留。

## 通过的检查

- `cargo test -p dustaway-core --locked`：170 项通过、2 项既有大规模资源基准按设置忽略。包括真实 AnalysisEngine 分页结果接入、已有识别优先、手工清理资格保持、旧消息兼容。
- 模型专项新增完整目录词项、中文目录、日志轮转、冲突上下文、保护扩展名、路径别名与备用数据流拒绝测试。
- `cargo test -p dustaway-core --locked --example file_purpose`：5 项通过，验证测试集不参与训练、跨组隔离、重复路径、同组洪泛、行顺序不变和每类至少两个训练组。
- `pnpm model:validate`：权重、基础报告、扩展评估与分组报告可复现，并再次运行训练器测试；已加入常规 `pnpm check` 流程。
- `cargo clippy -p dustaway-core -p dustaway-windows --locked --all-targets -- -D warnings`、`cargo fmt --all --check`、改动脚本的 Prettier 检查通过。
- 新 release CLI 实测：`D:\新软件\日志\service.log.17` 返回 `logs`；`D:\Cache\Documents\entry.cache` 返回 `conflicting_context`。只处理输入字符串，不读取文件。
