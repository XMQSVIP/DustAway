# 扫描与清理进度可见性修正（2026-10-02）

用户反馈：动态进度条在默认窗口下方，需要滚动才能看到。原布局将进度条放在大幅装饰图和扫描磁盘说明之后。

本次将进度条移入任务标题区域，与检查数量、当前项目和停止按钮集中显示；执行期间收起大幅装饰图。该区域在结果滚动时吸附于内容顶部，键盘滚动预留状态区空间。空闲首页及完成后的展示沿用原布局。

扫描仍是总量未知的动态条，清理仍按后台已处理数量显示进度；停止或状态不确定时不伪造进度。只修改前端布局，不改变扫描范围、清理规则、确认、停止、任务恢复或报告格式，版本仍为 0.18.0。
