## 真实桌面夹具

使用 `cargo build -p dustaway --features e2e-fixture,custom-protocol` 和 `node scripts/e2e.mjs`，后端必须声明 +e2e-fixture 才能执行删除。夹具仅位于带标记的专用临时目录。

实测通过：扫描、搜索、排序默认值、本页选择、主题保留、计划确认与返回、真实句柄删除、历史、自定义最大化与还原。新增实测包括：

- 文件资源管理器实际选中中文带空格的夹具文件，通过 Shell 选择状态核对。
- 从明细添加长期排除草稿，关闭明细后核对保存、重新扫描，候选中不再包含排除文件。
- 再次清理只删除另一个旧夹具文件；排除文件、近期文件和根外保护文档保留。
- 页面重载接回已完成任务，清空当前选择，不自动执行。
- 实际桌面窗口缩至 760×580 CSS 像素时，分页栏位于窗口内，无横向溢出；列表仍有约 221 px 高度。
- 使用 Tab、Enter、Escape 完成文件操作展开、资源管理器定位、添加排除、退出明细、核对并保存；检查目标焦点在可见区域内。

发现并修复两处真实问题：Shell 不接受句柄层的扩展路径表示；固定底栏遮挡滚动到窗口下部的草稿按钮。修复后上述桌面流程通过。底栏现在占据独立布局空间。

证据：`artifacts/desktop-e2e-0.3.json`、`desktop-minimum-0.3.png`、`desktop-details-light-0.3.png`、`desktop-details-0.3.png`。已查看浅色最小窗口与深色明细截图。当前缩放环境的一次实测不等于覆盖 100%–200% DPI 矩阵或屏幕阅读器。
