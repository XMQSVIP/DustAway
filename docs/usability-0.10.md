# 0.10 普通用户试用脚本

状态：人工可用性待验证。首轮目标五名非开发者，由项目所有者安排；尚未招募或访谈，不报告虚构成功率。每人约 20 分钟，普通权限，使用备份完成的专用测试账号与标记夹具。

## 主持人准备

准备系统卷空间提示、只读个人资料、可清理旧缓存、运行中应用、只读应用规则、零候选和部分成功案例。不要填满日常磁盘，也不要用参与者唯一的工作文件测试删除。不要提前教按钮位置；先让参与者解释自己的判断，卡住时记录，再提供帮助。除主动同意记录的测试数据外，不保存个人路径或屏幕内容。

## 任务

1. “电脑提示空间不足，请找出哪个位置占得多，并说明接下来准备怎么办。”记录能否进入磁盘分析、理解范围与待统计状态。
2. “这里有个很大的目录，请判断它是否能直接清理。”覆盖个人资料、系统数据、未知位置；让参与者说明用途依据和风险。
3. “查看对应类别，但暂时不要改变原来的清理选择。”检查查看与加入范围是否可理解，能否回到原分析位置。
4. “现在把该类别加入下一次扫描，保留你不想处理的文件，完成一次合适的操作。”观察排除草稿、重新扫描、计划确认与永久删除的理解；仅删除夹具。
5. 展示运行中、版本不支持、验收未完成三种情况。“为什么不能处理？你会怎么做？”判断是否误以为退出应用就能开放六条规则。
6. 展示零候选、部分成功或可用空间负增长。“这次实际做了什么？问题解决了吗？还可以去哪里处理？”随后在夹具环境模拟应用内处理，刷新同卷采样，检查是否误认为是拂尘删除成绩。
