# 0.18 非开发者可用性验证

状态：待执行。当前没有招募到参与者，0人参与；自动化和设计者自查不计入用户研究。

安排5名非开发者，在隔离测试电脑上使用可丢弃样本。不给操作指导，记录首次点击、完成时间、错误、求助、理解与原话。

| 任务 | 判断标准 |
| --- | --- |
| 扫描垃圾 | 找到唯一入口，理解扫描不删除 |
| 保留指定文件 | 打开明细、取消指定文件，返回后选择保留 |
| 解释需确认项目 | 能区分默认建议选择、主动选择与只读限制 |
| 完成清理 | 核对一次永久删除确认，正确理解实际结果 |
| 整理 uv 缓存 | 能找到独立官方工具入口，理解发现大小不等于可释放量，零收益不等于失败 |

通过标准：至少4人无需指导完成五项任务；5人均能区分默认选择与手动选择。记录按P1–P5匿名编号，不收集个人文件路径。未达到标准时记录具体障碍后修正，不补写成功数据。
