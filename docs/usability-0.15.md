# 0.15 非开发者试用任务

状态：**人工可用性待验证**。当前没有参与者记录，自动化通过不能替代实际试用。

招募五名非开发者，使用专用演示数据，不要求删除个人数据、登录测试账号或改变日常应用。主持人先说明目标：为一次保存或安装腾出空间，并保留需要的工作内容；不解释按钮位置。

1. 在最大文件排行发现模型或虚拟磁盘，找到对应处理建议，说出处理前应核对什么。
2. 查看浏览器资料，在指引中区分缓存和登录等其他数据；不执行日常账号清理。
3. 查看清理类别再返回，确认选择、搜索和原项目仍在。加入下次扫描范围必须由参与者明确操作。
4. 模拟外部整理后返回复核，说出刷新磁盘与重新分析的差别；指出磁盘变化不能归因于当前项目。
5. 结束本项核对，回到模拟保存或安装任务；若仍不足，继续查看其他占用。

逐人记录：是否独立找到入口、求助次数、误认为可直接删除/已经删除的次数、无效重扫、返回位置丢失、能否解释三个数值（文件大小、磁盘变化、拂尘删除量）。记录观察事实和原话，不采集私人路径、账号或文件内容。

目标：至少四人无需提示完成完整流程；全部参与者能区分三个数值及只读说明与清理权限。有失败时记录卡点再决定改动，不把未完成任务剔除。
