# 拂尘（DustAway）

面向 Windows 办公与日常用户的本地空间整理工具，使用 Rust、Tauri 2、React 和 TypeScript，MIT 开源。无账号、广告、遥测、后台常驻服务或在线规则。

## 当前开发与交付

当前源码版本 **0.25.0**，目标为未签名的小范围测试版。开发源码、候选包和已通过的验收分别记录；构建成功不表示真实应用恢复或用户试用通过。进展与交付状态见 [0.25.0 验收](docs/verification-025.md)。

[编译能力摘要](docs/current-capabilities.json)来自 Rust 注册表。[操作证据台账](docs/acceptance-ledger.json)区分官方依据、隔离测试入口和已有操作证据。规则数量不是本机已安装软件数量，也不是可释放容量。

- 常规清理：临时文件、已适配的浏览器及应用缓存、部分开发工具缓存；未开放项目只显示占用。
- 空间分析：目录排行、文件分页、用途解释和用户主动选择。用途小模型只补充说明，不授予删除权限。
- 聊天附件：微信、经典 QQ、QQNT 分别核验来源、账号、布局和格式，在独立清单中确认。
- 软件管理：官方卸载入口与独立残留核验；没有验收许可的残留保留。
- 安装版包含受限系统维护，按需申请管理员授权；免安装版不包含辅助组件、不支持提权清理。普通扫描不自动申请管理员权限。

## 使用与边界

开始扫描 → 核对选择 → 清理已选 → 一次永久删除确认。文件不进入回收站，不能撤销。扫描占用、已选文件大小、实际删除量及磁盘可用空间变化分别展示。

清理前检查安装与文件身份、目录链、应用运行状态、排除项和文件变化；不跟随重解析点，不清理多硬链接或云文件，不修改目标 ACL。一次性清单不会因重连或重启被重放。

应用版本用于观察与安装指纹；清理资格依据独立规则证据和实际身份、布局、组件、格式核验，不使用应用版本白名单。详情见 [兼容性策略](docs/cleanup-compatibility.md)。

微信代码/图形缓存、钉钉及 ToDesk 历史日志仍按本轮逐项证据决定是否开放；未完成恢复与功能验证时保持只读。

## 开发

Windows x64、MSVC/Windows SDK、Rust（rust-toolchain.toml）、Node.js 24、pnpm 10.30.3、WebView2。

```powershell
pnpm install --frozen-lockfile
pnpm desktop
pnpm check:quality
```

桌面开发模式会操作真实文件；删除验证使用专用夹具或已确认的可还原测试环境。
