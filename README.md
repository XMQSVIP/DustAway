## 本轮：默认简洁清理与自选删除

最新完善：勾选即加入，文件详情只负责查看和选择；自选清单支持搜索分页、父子合并及移除。后端只读统计与最终确认分开，空文件夹可独立清理。首页按所选磁盘分别显示空间，与分析位置独立。[本轮实现与验收](docs/verification-selection-experience.md)。

普通流程为“开始扫描 → 清理已选 → 一次确认”；结果按用途直接显示建议分类，具体文件使用侧边明细，技术原因按需展开。空间分析支持主动选择普通文件、完整文件夹，以及取消子项、跨页保留选择和长期排除。清单核验后统一永久删除，新增、占用或受保护内容保留，非空目录保留。

首页默认扫描 C 盘，支持单选、多选与全部磁盘。只在所选磁盘的已支持垃圾位置扫描，结果保留实际范围；磁盘缺失或身份变化不会自动扩大范围。移除应用内存储管理指引，保留用途说明和必要的保留原因。[本轮验证](docs/verification-disk-selection.md)。

自选能力不解锁应用缓存规则；新增的钉钉网页、代码缓存许可各自来自独立真实证据，仍须通过普通清理规则及准确版本校验。[使用方法](docs/user-guide.md) · [自选实现的历史验证](docs/verification-manual-cleanup.md)。

- 明细可定位文件、将文件或直接父目录加入长期排除草稿，核对保存后重新扫描。
- 取消勾选后立即更新选中数量和大小；后端生成一次性计划，单独确认后永久删除。
- 清理后的分类显示本次已删除、跳过、失败、不确定与未处理；可直接查看对应明细。扫描时大小不是当前剩余大小，需要手动重扫。
- 持久排除项、历史、隐去路径的诊断导出、系统明暗主题；切换主题不清空扫描。
- 无原生标题栏，使用统一配色的自定义顶栏，支持拖动、双击最大化、最小化、还原和关闭。

不会自动选择文档或下载等个人文件；用户可在空间分析后主动选择普通资料删除。聊天核心资料、登录与站点持久数据等受保护位置继续保留。不跟随重解析点，不清理多硬链接或云文件，只按冻结清单删除文件及其已空目录，不修改目标 ACL 或注册表。

当前交付不提供系统提权清理。辅助进程与 NSIS 配置保留在源码中，须显式启用实验 `system-cleanup` feature；其 Program Files 限制没有放宽。

## 开发和构建

环境：Windows x64、MSVC C++ Build Tools / Windows SDK、Rust（见工具链文件）、Node.js 24、pnpm 10.30.3、WebView2。

```powershell
pnpm install --frozen-lockfile
pnpm desktop
```

桌面开发使用真实普通用户目录。网页预览运行 `pnpm dev`，预览不扫描或删除文件。验证删除必须使用专用夹具。

```powershell
pnpm check
cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings
pnpm test:e2e
pnpm portable
```

`pnpm portable` 直接生成 `artifacts/portable/拂尘_<版本>_windows-x64/` 文件夹，不创建 ZIP 或安装器。目录包括 EXE、SHA-256 文件、许可清单和使用说明，不包含 helper。桌面 E2E 需要匹配的 EdgeDriver，见 [测试指南](docs/testing.md)。

## 数据、更新和退出

中文产品名为“拂尘”，内部 Cargo/npm 标识及应用 ID 保留 DustAway，避免旧数据迁移。

设置和摘要继续位于 `%LOCALAPPDATA%\DustAway\history.sqlite`，WebView2 数据也存于当前用户目录。程序目录无需写权限。排除路径属于设置，会保存在本机；候选路径和文件快照仅存在内存会话中。

清理摘要默认保留 30 天，在启动、恢复和历史读取时维护；不清除运行中的报告。界面读取最近最多 100 条，旧版摘要仍可查看。

更新时退出旧程序，打开新版文件夹后运行。移动程序不会丢失当前用户设置。清理不会进入回收站；取消和退出只停止后续操作，已经删除的文件不恢复，中断后不自动续删。

## 工程结构

| -------------------------- | ---------------------------------------------- |
| `crates/core`              | 规则、会话、查询索引、计划、日志与恢复         |
